### I.1. Exact tau functions, with no sigma functions

Let C be y^2=f(x), f=x(x-1)(x-2)(x-5)(x-6), let P=(3,6), and let G=[P-infinity]. Write t=x-3 and

  y(3+t)=sum_(j>=0) b_j t^j,
  b_0=6,
  12 b_j=f_j-sum_(i=1)^(j-1) b_i b_(j-i),
  (f_0,...,f_5)=(36,36,-13,-13,1,1).

Here f_j=0 for j>5. All calculations are rational, and the chosen square root is unambiguous. In particular b_1=3, and 12^(j-1)b_j is integral for j>=1, by induction.

For a subset S of {0,1,2,5,6} of size s<=2, put

  T_S=sum_(a in S)[(a,0)-infinity],
  g_S(x)=product_(a in S)(x-a).

These sixteen subsets represent the sixteen rational 2-torsion classes. For n>=3 take the following basis, ordered by increasing pole order at infinity:

  g_S(x)t^j, with 2(s+j)<=n+s+1;
  y t^j, with 5+2j<=n+s+1.

There are exactly n functions. Let Delta_n^S be the determinant whose rows are the coefficients of t^0,...,t^(n-1) of these functions. Define

  tau_n^S=12^((n^2-n-2)/2) Delta_n^S.                 (1)

This is an exact formula for every seed and every term, rather than an instruction to fit a recurrence. The JSON certificate records seeds n=3,...,14 for all sixteen S. The functions are rational and in this example integral: row i has denominator dividing 12^max(i-1,0), whereas the exponent in (1) is at least the sum of these row bounds.

#### PROVED: incidence theorem

For n>=3,

  tau_n^S=0 iff nG+T_S is represented by [Q-infinity] for some Q in C(Q).

Proof. The determinant vanishes precisely when a nonzero h=A(x)+B(x)y, with pole order at most n+s+1 at infinity, vanishes to order at least n at P and vanishes at every (a,0), a in S. The latter conditions say g_S divides A. The remaining zero divisor has degree at most one. Thus

  div(h)=nP+sum_(a in S)(a,0)+Q'-(n+s+1)infinity

with infinity allowed as Q'. Hence nG+T_S=[bar(Q')-infinity]. Conversely, that divisor-class identity produces exactly such a function h. The explicit pole-ordered basis proves the equivalence without any rank theorem or sigma-function identity. Over Q, a residual divisor of degree one is a rational point.

This argument is valid over any field of characteristic different from 2 in which P remains nonbranch, with the usual interpretation over its algebraic closure. Over F_7, P remains nonbranch and all the normalizing powers of 12 are units.

#### PROVED: Cramer-rule bridge to Mumford coordinates

On the chart Delta_n^S != 0, let h=A+B y be the unique function with largest pole coefficient 1 in L((n+s+2)infinity), vanishing at nP and at the branch points in S. The coefficient of t^n in h is

  H_n=Delta_(n+1)^S/Delta_n^S.

The coefficient B(3) is obtained by deleting the y-column of its jet matrix. The y-column has index 3-s, counting from zero. After deletion, row zero contains only g_S(3). Delete that row and column, and factor t from every remaining function. The remaining determinant is Delta_(n-1)^S. Therefore

  B(3)=(-1)^(n+3-s) g_S(3) Delta_(n-1)^S/Delta_n^S.

The norm h*bar(h)=A^2-B^2 f has leading coefficient delta=(-1)^(n+s), and is divisible by t^n g_S(x). Its residual monic quadratic is the Mumford u-polynomial of nG+T_S, since its other two zeros represent the negative of that class, which has the same u-polynomial. At t=0, h*bar(h) has coefficient -12 B(3)H_n. Consequently

  u_(nG+T_S)(3)
    =-12 B(3)H_n/(delta g_S(3))
    =12 Delta_(n+1)^S Delta_(n-1)^S/(Delta_n^S)^2
    =tau_(n+1)^S tau_(n-1)^S/(tau_n^S)^2.           (2)

The second difference of (n^2-n-2)/2 is 1, which explains precisely the factor 12 in (1).

The same proof works for a generic degree-two initial divisor with Mumford coordinates (u_0,v_0): replace g_S t^j, y t^j by u_0 t^j, (y-v_0)t^j. It also works for a degree-one initial point Q=(a,b), using (x-a)t^j, (y-b)t^j and cutoff n+2. The norm argument and the deleted-column calculation are unchanged.

There is a precise boundary lemma; an unspecified appeal to a limiting gauge would leave a gap. For r=0,1,2 define E_(n,r) to be the determinant with n jet rows at P followed by r evaluation rows at Q_1,...,Q_r, with columns the ordinary pole-ordered basis of L((n+r+1)infinity). This square matrix has size n+r. For generic degree-two initial divisor Q_1+Q_2-2infinity, replacing its basis by

  1,x,u_0 t^j,(y-v_0)t^j

is a triangular change with diagonal 1, ordered by poles. Expansion in the two evaluation rows gives

  E_(n,2)=(x(Q_2)-x(Q_1)) Delta_n^(u_0,v_0).

For a single initial point the corresponding basis is 1,(x-a)t^j,(y-b)t^j, and

  E_(n,1)=(-1)^n Delta_n^Q.

For r=0, E_(n,0)=Delta_n^empty. These factors are themselves A B^n gauges.

Now let the last point Q_r approach infinity, with the uniformizer z=x^2/y. Then x=z^-2+lower-pole terms and y=z^-5+lower-pole terms. The final basis function is the unique column of largest pole order n+r+1, with leading coefficient 1. Expanding in the final evaluation row therefore proves the exact leading-term identity

  lim_(Q_r -> infinity) z^(n+r+1) E_(n,r)=E_(n,r-1).           (B)

The multiplier is z^(r+1)*(z)^n, exactly an A B^n gauge. This establishes the claimed normalization at the boundary; it is not inferred from two numerical seeds. Apply (B) twice for the empty initial divisor, or once for a degree-one initial divisor. Finite branch-point specializations give every S of size one or two. The powers of 12 in (1) do not change with r.

Thus identities first proved for generic initial divisors extend to every required torsion coset, including zero tau terms. Clear denominators in a common projective Kummer chart before specializing. Both sides of the resulting polynomial identity have the same gauge factor, so (B) gives the required identity for the explicit determinants (1). This is continuation of rational polynomial identities and their explicitly computed leading coefficients, not an invocation of analytic sigma functions. Statements involving only indices >=3 follow directly; the finitely many lower-index Cantor identities use c0=c1=0,c2=1,c_(-n)=-c_n and are checked separately.

### I.5. Modulo 7, the zero-aware atlas and the gauge

  tau_j tau_(j-8)=2 tau_(j-2)tau_(j-6),
  tau_j tau_(j-10)=4 tau_(j-4)tau_(j-6),

### II.4. The elementary difference lemmas

The formal-group input used here is the same elementary one used in P05–P06: in integral local coordinates at a good odd prime, addition is an integral formal power series. If D is in the first formal kernel, translation T by D has

    T=I+pK

with K an integral power series. This statement is obtained from the Cantor addition law and its unit-denominator local charts; it is not a global rank theorem. For any integral analytic observable f, let Delta f=f composed with T minus f. Then

    Delta^j f belongs to p^j Z_p[[local coordinates]].

Consequently, on a fixed orbit through z,

    F(t)=f(T^t z)=sum_(j>=0) binom(t,j) Delta^j f(z).       (NEWTON)

The series converges for t in Z_p. It agrees with the ordinary finite-difference identity for nonnegative integer t and hence, by continuity, with the completed orbit. After expansion in powers of t, it is a restricted integral series: the j-th Newton coefficient has valuation at least j, and division by j! costs at most v_p(j!).

PROVED LEMMA 1 (symmetric quadratic isolation). Suppose p>=5, F(0)=0, F(-t)=F(t), and v_p(F(1))=2. Under (NEWTON),

    F(t)/p^2 = c*t^2 + p*t^2 H(t),

where c is a p-adic unit and H is an integral restricted series. In particular

    v_p(F(t))=2+2v_p(t) for nonzero t in Z_p,

and t=0 is the only zero.

Proof. The constant coefficient is zero. Evenness makes the linear coefficient zero. All power coefficients of degree >=3 are divisible by p^3, since j-v_p(j!)>=3 for j>=3 and p>=5. The quadratic coefficient is divisible by p^2. Evaluating at 1 proves that coefficient divided by p^2 is a unit. Factoring t^2 gives the claim. The same estimates show restricted convergence of H.

PROVED LEMMA 2 (two exact roots at a tangential return). Suppose p>=5, F(0)=F(-1)=0, and F(1)/p^2=c is a p-adic unit. Then

    F(t)/p^2 = (c/2)t(t+1) mod p

as an integral restricted power series, with every coefficient above degree two divisible by p. Hence F has exactly the two zeros 0,-1 on Z_p.

Proof. The Newton coefficient Delta f(z)=F(1) is divisible by p^2. Since F(-1)=0, evaluating (NEWTON) at -1 gives

    -Delta f(z)+Delta^2 f(z)=0 mod p^3.

All terms with j>=3 vanish modulo p^3. Therefore after division by p^2 the first two Newton terms are

    c*t+c*binom(t,2)=(c/2)t(t+1) mod p.

The factorial bound shows that higher power coefficients are divisible by p. Strassmann's elementary coefficient argument bounds the number of zeros by two; the two exact known zeros attain it. Equivalently, the two simple roots modulo p each lift uniquely. No symmetry hypothesis is needed for Lemma 2.

These are lifting.dynamical statements about observable recurrences. Lemma 2 is a useful additional card: it certifies a tangential residue class by two exact zeros and one nonzero second-level difference, rather than by constructing an annihilating differential.

### II.8. What this does not certify about the raw Somos state

#### III.1.5. PROVED: the polynomial reverse map has no extra filters

Proof. Q>0, since u=w=0 does not satisfy F1=-1. The identities already

    R^2-5Q^2=-4,
    Z=2s,

### III.2. PROVED: all three equations lie in one concrete cyclic quartic field

Set

    t=sqrt(5), rho=sqrt(10+2sqrt(5)),
    K=Q(rho), rho^4-20rho^2+80=0.

The degree of K is four. Indeed t=(rho^2-10)/2 is in K. If rho=a+b t with
a,b rational, then ab=1 and a^2+5b^2=10, so a^2 would satisfy

Then rho'^2=10-2t, and the map t -> -t, rho -> rho' is an automorphism of
order four, since its square sends rho to -rho. Thus the field is cyclic.

The actual Thue generators are

    beta1 = (t-1)(rho-3)/2,
    beta5 = 2rho-3t,
    betab = (1+beta5)/(1-beta5).

    beta1: -61/16; beta5: 244; betab: 61/16.

    Norm_K/Q(w-beta5 U) = -F5(U,w),
    Norm_K/Q(A-betab B) = -Fb(A,B).

Thus every covering equation is an equation for an integral element of
norm one. Such an element is a unit by the integer adjugate of its
multiplication matrix; no description of the full unit group is needed.

In the basis (1,beta,beta^2,beta^3), the two markers are precisely the

### III.3. PROVED: the one-binomial obstruction applies to the actual forms

For F=A X^4+B X^3Y+C X^2Y^2+D XY^3+E Y^4 define

    J=72ACE+9BCD-27AD^2-27B^2E-2C^3.

    F1: I=1585, J=-112750;
    F5: I=25360, J=-7216000;

The exact substitutions above explain the scaling: Fb is obtained by a
determinant-1 matrix, while F5 is obtained by a determinant-minus-2 matrix.
Thus I scales by 2^4=16, J by 2^6=64, and the discriminant by 2^12=4096.
In particular J != 0 for all three. Indeed the three-by-three matrix

    [[A,B/4,C/6],[B/4,C/6,D/4],[C/6,D/4,E]]

has determinant J/432. For a fourth power of a linear form it has rank one, so a sum of two such fourth powers has rank at most two. An invertible linear variable change multiplies J by the sixth power of its determinant, as direct expansion verifies. Thus J!=0 remains nonzero after any such change and any field extension. This elementary catalecticant argument
rules out writing any actual covering form as a sum of two fourth powers
of linear forms, after any invertible linear change of its two variables
and over any coefficient-field extension. This is stronger information
than testing only the original square-valued quartic Phi.

    theta^4-2theta^3-6theta^2+2theta+1=0,

    beta1=(-5theta^2+22theta-3)/(6theta+4),

of a binomial description of the field. A scalar one-binomial separator

### III.4. The exact simultaneous approximation target

Put U0=2+4i, V0=2-4i, w0=V0/U0, and choose W with W^4=w0. A suitable choice

The other branches give its other roots. Substitution yields beta=C(W)/D(W)

    beta*: C*(W)=3+4W+3W^2, D*(W)=i(W^2-1).

This single pair suffices for the one-form cover F1=-1. For independent

    C1(W)=(2+22i)-16W+(2-22i)W^2,
    D1(W)=(4+6i)+8W+(4-6i)W^2;

    D5(W)=i(1-W^2);

    Cb(W)=-[(3+2i)+4W+(3-2i)W^2],
    Db(W)=(3+i)+4W+(3-i)W^2.

The beta* pair C*,D* is the first target: the other pairs are redundant
charts. Passing to an octic or degree-16 field is unnecessary for

of theta induced by a seed still gives quadratic C,D in W. The denominator

#### III.4.1. PROVED: the determinant exponent that must be beaten

Suppose for every sufficiently large index j there are three independent
Gaussian integer triples z_(j,r)=(q_(j,r),a_(j,r),b_(j,r)), r=0,1,2, with

    max(|q|,|a|,|b|) <= C_Q Q^j,
    |qW-a|, |qW^2-b| <= C_E E^(-j),

where Q>1,E>1 and the three triples have nonzero determinant. Fixed
polynomial factors in j can instead be absorbed by taking any slightly
larger Q and slightly smaller E. Let beta=C(W)/D(W) be a real irrational
target with Gaussian quadratic C,D and D(W) != 0. Form

    p'=c0 q+c1 a+c2 b,
    q'=d0 q+d1 a+d2 b.

The corresponding complex linear error q' beta-p' is bounded by a constant
times E^(-j), and |q'| by a constant times Q^j. For every rational P/H, H>0,
at least one of the three Gaussian integers

    H p'-P q'

is nonzero: if all vanish, the nonzero linear functional H C-P D would
annihilate three independent vectors, forcing C and D to be proportional.
Their ratio would then be in Q(i), and real beta would be rational,
contrary to the hypothesis. A nonzero Gaussian integer has modulus >=1.
Choose the first j for which H times the error bound is <=1/2. The ordinary
two-term determinant estimate gives

    |beta-P/H| >= c H^(-mu),
    mu=1+log(Q)/log(E),

with an explicit c from the displayed constants. For a quartic Thue
equation, the small linear factor gives |beta-P/H| <= C H^(-4). Thus the
strict useful threshold is

    mu < 4, equivalently Q < E^3.

A proof of the upper bound needs only fixed root separation: for a degree-4
form with distinct real roots, outside a finite bounded range, a solution
of fixed nonzero right-hand side has exactly one small root factor, while
the other three are at least fixed constants times |H|. The constants are
computable from elementary isolating intervals for the four roots.

There is also an intrinsic lower restriction on simultaneous approximation.
Subtract W times the first column from the second and W^2 times the first
from the third in the three-by-three determinant. Its modulus is at most
a constant times (Q/E^2)^j. Since it is a nonzero Gaussian integer, this
forces E^2 <= Q at the exponential-rate level. Therefore the genuinely
available window is

    Q^(1/3) < E <= Q^(1/2), or 3 <= mu < 4.

This window is nonempty. It is exactly why a joint construction can in
principle do what a naive product of separate approximants cannot.

#### III.4.2. PROVED obstruction to separate denominators or naive quadratic projection

Consider separate scalar approximation sequences for W and W^2, with
Gaussian integer denominators of sizes Q1^j,Q2^j and linear errors
E1^(-j),E2^(-j). Assume nonzero consecutive scalar cross determinants, and
uniform upper estimates with these exponential rates. The determinant
estimate forces E1 <= Q1 and E2 <= Q2.

Making a common denominator by multiplication gives

    q=q1 q2,  a=a1 q2,  b=a2 q1,

with error bases E1/Q2 and E2/Q1. To certify that both errors decay, one
would need E1>Q2 and E2>Q1. These contradict E1<=Q1 and E2<=Q2. Thus this
specific architecture cannot give contracting common-denominator errors.
An exponentially growing common divisor, or a proved correlation permitting
better estimates, would change the arithmetic data and evade the statement.

There is an equally direct scalar version. Starting with (q,a) approximating
W, a quadratic rational projection produces integer homogeneous quadratic
expressions in q,a. Their size is O(Q^(2j)); their linear error is only
O((Q/E)^j). The scalar determinant restriction E<=Q makes this certified
error noncontracting. This is the precise naive reconstruction barrier.
It does not exclude a simultaneous Hermite-Pade construction.

#### III.4.4. What a seed must accomplish

The simplest-quartic identity is

    U0(p-iq)^4 - V0(p+iq)^4 = 8i F_2(p,q),

where

    F_2(p,q)=p^4-2p^3q-6p^2q^2+2pq^3+q^4.

Thus U=U0(p-iq)^4 has

    |U|=sqrt(20)(p^2+q^2)^2,
    |U-bar(U)|=8|F_2(p,q)|.

Multiplying U by -1 if necessary makes its real part positive near a good
seed. The sufficient simultaneous criterion is a completely explicit
integer comparison after squaring:

    20(p^2+q^2)^4 > 2^82 * 8^18 * F_2(p,q)^18.

This intentionally conservative construction requires an exceptionally
good seed. If H=max(|p|,|q|) and a root approximation has quality
|p/q-theta| of order H^(-tau), with |q| comparable to H, then

    |U| of order H^4,
    |F_2(p,q)| of order H^(4-tau).

The sufficient inequality requires tau>32/9 asymptotically. Ordinary
pigeonhole approximation gives exponent 2 and cannot guarantee this.
For comparison, the one-binomial quartic separator for F_2 itself asks for
the weaker exceptional exponent 8/3; it does not directly solve the
quadratically reconstructed target forms. Neither threshold is a theorem

the constants, removing certified common factors, choosing a different

## Part IV. A common-denominator hypergeometric separator with a proved determinant

### IV.H1. Scope and status

PROVED below: an elementary, common-denominator, three-column construction for

    1, Z, Z^2, where Z=(Ubar/U)^(1/4), U in Z[i].

It has a nonzero determinant at every nonreal U, explicit size and error bounds, and a sufficient quantitative condition under which it separates rational approximations to every nonconstant quadratic rational function of Z with exponent strictly smaller than four.

UNPROVED for the fixed Fibonacci forms: existence of a transported seed satisfying this sufficient condition. The constants below are deliberately conservative and are not optimized hypergeometric constants. Thus this is a genuine construction and a precise remaining arithmetic target, not a claim to have solved that quartic.

### IV.H2. Integer Padé weights

For N>=0 put

    Lambda_N={4k+i : 0<=k<=N, i=0,1,2},
    d=3N+2,
    R_N=4N+2,
    D_N=(4N+2)! * 2^v_2(N!)/N!,
    b_lambda=D_N / product_(nu in Lambda_N,nu!=lambda)(lambda-nu).

PROVED: every b_lambda is an integer, and

    sum_(lambda in Lambda_N) |b_lambda| <= 4*128^N.          (H1)

Proof. Among 0,...,4N+2 the omitted integers are 4j+3, 0<=j<N. Since 4N+2 is even,

    b_lambda=(-1)^lambda binom(4N+2,lambda)
      * [2^v_2(N!)/N!] product_(j=0)^(N-1)(lambda-4j-3).

For any odd prime p and any a>=1, an arithmetic progression of N terms with difference 4 contains at least floor(N/p^a) multiples of p^a. The product therefore contains the odd part of N!. The factor 2^v_2(N!) removes the entire remaining denominator. This proves integrality using only divisibility of integers.

Write lambda=4k+i. Splitting the product at j=k gives

    product |lambda-4j-3| <= 4^k k! * 4^(N-k)(N-k)! <= 4^N N!.

Together with 2^v_2(N!)<=2^N and sum binom(4N+2,lambda)<=2^(4N+2), this proves (H1).

Lagrange interpolation also gives, exactly,

    sum b_lambda lambda^j = 0, 0<=j<d,
    sum b_lambda lambda^d = D_N.                          (H2)

For example, take the coefficient of x^d in the Lagrange interpolation formula for x^j on the d+1 nodes. No analytic approximation theorem is required.

### IV.H3. An exact nonzero three-by-three determinant

For r,i in {0,1,2} define integer polynomials

    M_(r,i)(w)=sum_(k=0)^N b_(4k+i)(4k+i)^r w^k.

These are explicit terminating generalized hypergeometric polynomials, although no hypergeometric theorem is needed. If b_(4k+i)=b_k^(i) and {l_1,l_2}={0,1,2} minus {i}, then

    b_(k+1)^(i)/b_k^(i)
      =[(k-N)/(k+1)]
       product_(l!=i) [(k+(i-l)/4-N)/(k+(i-l)/4+1)].

Consequently, with (a)_k=a(a+1)...(a+k-1),

    M_(0,i)(w)=b_i sum_(k=0)^N
      [(-N)_k product_(l!=i)(-N+(i-l)/4)_k]
      /[k! product_(l!=i)(1+(i-l)/4)_k] * w^k,
    M_(r,i)=(4w d/dw+i)^r M_(0,i).

Thus a reproducible three-function hypergeometric system, including its derivative rows, is specified exactly.

Let Z=w^(1/4), with the branch near w=1. The r-th row form is

    L_r(w)=sum_(i=0)^2 M_(r,i)(w) Z^i
          =sum_(lambda in Lambda_N) b_lambda lambda^r exp(lambda z),
    z=(log w)/4.

By (H2), L_r has a zero of order at least d-r at w=1. Replacing column 0 of M by column 0+Z column 1+Z^2 column 2 does not change its determinant. Expansion in that column shows that det M has a zero of order at least d-2=3N at w=1. Its degree is at most 3N. Its leading coefficient is a Vandermonde determinant on 4N,4N+1,4N+2, multiplied by the top three weights. Therefore

    det M(w)=C_N(w-1)^(3N),
    C_N=2 b_(4N)b_(4N+1)b_(4N+2) != 0.                 (H3)

This is an exact identity for every N, including N=0. It supplies the determinant which a mere dimension count or a floating-point Padé fit would not provide.

### IV.H4. Specialization in the Gaussian integers

Let U in Z[i] be nonreal, Re U>0, and |arg U|<=pi/4. Write

    V=Ubar, w=V/U, Z=w^(1/4),
    R=|U|, h=|arg U|/2,

choosing the branch with log w=-2i arg U, so z=-i arg U/2 and |z|=h<=pi/8<1. Define

    A_(r,i)=U^N M_(r,i)(V/U)
           =sum_(k=0)^N b_(4k+i)(4k+i)^r V^k U^(N-k).

All A_(r,i) belong to Z[i], and

    det A=C_N(V-U)^(3N) != 0.                            (H4)

For N>=1, (H1) immediately gives the row-size bound

    max_(r,i) |A_(r,i)| <= 144 N^2 (128R)^N = S_N.        (H5)

We next need a uniform residual estimate, including the small prefactor. For distinct real nodes x_0,...,x_d, repeated applications of the fundamental theorem of calculus give

    |sum f(x_j)/product_(l!=j)(x_j-x_l)|
      <= sup_(x in [min x_j,max x_j]) |f^(d)(x)| / d!.

One may prove this first for two nodes, then iterate the divided-difference identity; equivalently, the divided difference is the integral of f^(d) on the standard d-simplex, whose volume is 1/d!. This is an elementary integral identity for complex-valued f as well.

Apply it to f(x)=x^r exp(zx), with r<=2. Because z is purely imaginary,

    |f^(d)(x)| <= sum_(l=0)^r binom(d,l)(r)_l R_N^(r-l) h^(d-l),

where (r)_l=r(r-1)...(r-l+1). Also

    D_N/d!=binom(4N+2,N) 2^v_2(N!) <= 4*32^N.

Since d-r>=3N, h<=1, and R_N+d+1=7N+5<=12N for N>=1, we obtain

    |sum_(i=0)^2 A_(r,i) Z^i|
       <= 576(1+h)^2 N^2 (32R h^3)^N = T_N.            (H6)

The inequalities remain valid when h is very small. We have not replaced a small error prefactor by an arbitrary constant that could invalidate a later threshold.

### IV.H5. Simultaneous approximations from the adjugate

Take the three cross products of pairs of rows of A. Write any such cross product as v=(q,p_1,p_2). These three Gaussian-integer triples are linearly independent, since det A!=0. Direct cross-product identities give

    |q|,|p_1|,|p_2| <= 2 S_N^2,
    |qZ-p_1|,|qZ^2-p_2| <= 2 S_N T_N.

Thus, at the same index N, there are three independent simultaneous approximants with

    max |v_i| <= 41472 N^4 Q_0^N,
    max(|qZ-p_1|,|qZ^2-p_2|)
       <= 165888(1+h)^2 N^4 E_0^(-N),                  (H7)

where

    Q_0=16384 R^2=2^14 R^2,
    E_0=1/(4096 R^2 h^3)=1/(2^12 R^2 h^3).           (H8)

The same common denominator approximates both functions. Forming two unrelated scalar approximants and multiplying their denominators does not have these error bounds.

### IV.H6. A separator for quadratic rational images

Let a=(a_0,a_1,a_2), b=(b_0,b_1,b_2) belong to Z[i]^3 and be linearly independent. Suppose

    beta=(a_0+a_1 Z+a_2 Z^2)/(b_0+b_1 Z+b_2 Z^2)

is real and irrational, and the denominator is nonzero. Put

    C_b=|b_0|+|b_1|+|b_2|,
    C_beta=|a_1-beta b_1|+|a_2-beta b_2|.

Certified rational upper bounds for these constants may be substituted. Under the stated independence and nonzero-denominator hypotheses C_b and C_beta are positive.

Assume the strict rate condition

    Q_0<E_0^3.                                          (H9)

Choose any real eta>1 satisfying eta^4 Q_0<E_0^3, and put

    Q=eta Q_0, E=E_0/eta,
    kappa=log Q/log E < 3,
    B_eta=(4/log eta)^4,
    C_Q=41472 C_b B_eta,
    C_E=165888(1+h)^2 C_beta B_eta.

Here E>1 follows from (H9), since Q_0>1. The elementary maximum of x^4 exp(-x log eta) gives N^4<=B_eta eta^N. For each of the three triples v define

    P=a dot v, Qden=b dot v.

Then

    |Qden|<=C_Q Q^N,
    |beta Qden-P|<=C_E E^(-N).                         (H10)

For every rational p/q with integers p,q, q>=1, and 2 C_E q>=1, we have

    |beta-p/q| >= 1/[K q^(1+kappa)],
    K=2 C_Q Q (2 C_E)^kappa.                           (H11)

Proof. Choose N>=1 least with E^N>=2 C_E q. Then Q^N<=Q(2 C_E q)^kappa. For at least one of the three independent vectors v, the Gaussian integer qP-p Qden is nonzero: otherwise the nonzero row q a-p b would annihilate a basis. Its absolute value is at least 1. Therefore

    1 <= |qP-p Qden|
       <= q |P-beta Qden| + q |Qden| |beta-p/q|
       <= 1/2+q C_Q Q^N |beta-p/q|.

This proves (H11). No condition that an individual Qden be nonzero was assumed; the chosen nonzero cross determinant plus the error bound forces it automatically. Small q with 2 C_E q<1 form an explicitly bounded finite exceptional set.

If beta is a root of a degree-four Thue form, its sufficiently close solutions satisfy |beta-p/q|<=C/q^4, with an explicit C obtained from root separation. Combining this with (H11), because kappa<3, gives

    q^(3-kappa)<=CK.

That is an effective elementary height bound. All real conjugates must be treated; replacing Z by i^j Z changes only the coefficient vectors a,b and their finite constants.

### IV.H7. An invariant-looking sufficient seed score

Condition (H9) is exactly

    2^50 R^8 h^9<1.                                     (H12)

Put delta=|U-Ubar|. On |arg U|<=pi/4 we have

    h=|arg U|/2 <= |sin(arg U)| = delta/(2R).

Consequently the concrete inequality

    R>2^41 delta^9                                      (H13)

is sufficient. It is very conservative but completely explicit.

For the simplest-quartic t=2 presentation use

    F_2(p,q)=p^4-2p^3q-6p^2q^2+2pq^3+q^4,
    U_0=(2+4i)(p-iq)^4.

Then, by direct expansion,

    Im U_0=4 F_2(p,q),
    |U_0|=sqrt(20)(p^2+q^2)^2,
    |U_0-Ubar_0|=8|F_2(p,q)|.

For a primitive seed in the correct angular sector, therefore,

    sqrt(20)(p^2+q^2)^2 > 2^41 [8|F_2(p,q)|]^9          (H14)

is a sufficient condition for the joint separator. More precisely, for t=p-iq and U_new=(2+4i)t^4, the new and old fourth roots satisfy

    Z_new=zeta Z_old * bar(t)/t, zeta in {1,i,-1,-i}.

Hence Z_old=zeta^(-1)(t/bar(t))Z_new. Substitute this into the quadratic coefficient pairs of Part III and clear the fixed Gaussian denominator. This changes the finite constants C_Q,C_E, but not the exponential bases. To treat all four real roots, use all four values of zeta.

Only replacing U_new by -U_new is used to choose positive real part; it leaves Ubar/U unchanged. Multiplication by i would change the quotient and is not silently allowed. A seed satisfying (H13) already has |Re U_new|>|Im U_new|, since its nonzero Gaussian integer imaginary part has absolute value at least one and (H13) forces R much larger than 2|Im U_new|. Thus the harmless sign choice puts it in the sector required by Section IV.H4.

UNPROVED: a seed satisfying (H14) exists for this fixed form. We do not infer its existence from ordinary continued fractions, the unit group, or a search. With H=sqrt(p^2+q^2), a root approximation of order H^(-tau) has |F_2(p,q)| of size H^(4-tau). At the level of these exponents, (H14) requires

    4>9(4-tau), or tau>32/9.

This is an exceptional-approximation requirement. The exponent comparison is an asymptotic diagnostic under the stated size assumptions, not a theorem that rules out sporadic successful seeds. A substantially better denominator cancellation, a sharper multivariate Padé normalization, or a different joint construction is therefore the most useful next computational target.

The sufficient condition is not vacuous in families: U=2^80+4i satisfies (H13), since delta=8 and 2^80>2^41*8^9. This example demonstrates the theorem on a family of quadratic rational images of fourth roots. It is not asserted to be a seed of the fixed t=2 quartic.

### IV.H8. A sharp dimension obstruction for a natural competing class

PROVED. Let r>=1, let f=(1,z_1,...,z_r) be fixed complex numbers, and suppose that for arbitrarily large N there are r+1 linearly independent vectors

    v_j=(q_j,p_(j,1),...,p_(j,r)) in Z[i]^(r+1)

satisfying |v_j|<=C_Q Q^N and |q_j z_l-p_(j,l)|<=C_E E^(-N), with constants independent of N. Then

    E^r<=Q.

Proof. Subtract z_l times column 0 from column l of their determinant. The determinant is a nonzero Gaussian integer, so has absolute value at least one. Its expansion is bounded by

    (r+1)! C_Q C_E^r (Q/E^r)^N.

If E^r>Q, this tends to zero, a contradiction.

Accordingly a determinant separator from such a system has irrationality exponent 1+log Q/log E>=r+1. Simultaneously approximating the entire degree-d power basis (r=d-1) cannot give a strict exponent smaller than d within this natural equal-rate/common-height architecture. For the quartic target, r=2 is precisely the smallest potentially useful system after the degree-two generator maps: the feasible rate window is

    E^2<=Q<E^3.

This obstruction applies to the specified linear-independent simultaneous approximation architecture. It is not a theorem that all Hermite--Padé, norm, congruence, or arithmetic descent mechanisms fail.

## Part V. The reusable theory and the next exact tasks

### V.1. PROVED: local saturation can replace a global generator certificate

Here is the coverage theorem actually used, in a form which extends beyond rank one.

Let A be an abelian group for which an elementary descent has proved finite generation of free rank r. Let U be a torsion-free integral formal group at an odd prime p, and suppose L=A cap U has rank r. Assume explicit D_1,...,D_r in L have linearly independent images in U/pU. In an integral formal chart U is the first congruence neighbourhood, so these images can be certified by a nonzero r-by-r minor of the first coordinate vectors divided by p modulo p. Then

    L is contained in Z_p D_1+...+Z_p D_r.

In fact these two sets have the same closure in U.

Proof. As an abstract group, L has some integer basis E_1,...,E_r. Write the D_i in that basis, with integer coefficient matrix M. The stated independence implies det M is a p-adic unit: otherwise a nonzero relation between its columns modulo p would give a relation between the images of the D_i in U/pU. Therefore M is invertible over Z_p. Approximate every coordinate of M^(-1)v, for v in Z^r, by integers and use the continuous integral formal group law. This writes each element sum v_i E_i as a limit of integer combinations of the D_i. The reverse closure inclusion is immediate.

This theorem does not assert a global index of one. It proves exactly the local coverage that an isolation argument needs. In the present example r=1 and the single test is D notin 7U. It is a useful replacement for an unnecessary global saturation computation whenever a small prime gives a primitive formal direction.

### V.2. PROVED: finite differences give a higher-order root certificate

Let p be prime, 1<=d<=p-2, and let T=I+pK be an integral analytic return map on an integral formal chart. For an integral analytic marker f and base z write

    Delta f=f composed with T-f,
    F(t)=f(T^t z), t in Z_p.

Assume

    Delta^j f(z) belongs to p^d Z_p, 0<=j<=d,
    v_p(Delta^d f(z))=d,

and assume d explicitly known zeros a_1,...,a_d of F lie in Z_p and are pairwise distinct modulo p. Then those are all zeros, and for every t in Z_p,

    F(t)=p^d unit(t) product_(i=1)^d(t-a_i),

where unit(t) is an integral restricted power series nonzero modulo p. In particular

    v_p(F(t))=d+sum_i v_p(t-a_i)

away from the listed zeros.

Proof. The Newton series has j-th coefficient Delta^j f(z). For j>d the power coefficients contributed by binom(t,j) have valuation at least j-v_p(j!)>=d+1, since d<=p-2. Hence F/p^d is an integral restricted series whose reduction modulo p is a polynomial of degree exactly d, with leading coefficient (Delta^d f(z)/p^d)/d! nonzero. The d exact roots identify that polynomial as c product(t-a_i), c!=0. Division of a restricted power series by t-a_i, when its value at a_i is zero, is elementary convergent synthetic division. Repeating the division and reducing modulo p leaves the constant c. The remaining factor is therefore a unit everywhere on Z_p. This proves the statement.

This is a finite certificate using values or differences, not a general method of finding the exact roots. The symmetric repeated-root variant in Part II deals with t^2 directly. For the two ordinary discs of our curve, d=2 and the exact roots are 0,-1 or 0,1.

### V.3. PROVED card: a primitive theta-product recurrence

The following is the portable content of Q1. It is a theorem with checkable hypotheses, rather than a claim about every cluster recurrence.

Suppose a genus-2 curve and a divisor translation G have:

1. An elementary jet determinant tau_n^c for the required cosets c, with a proof that its zero is equivalent to theta incidence.
2. Explicit Kummer coordinates k, fixed-G differential addition polynomials B_ij, and four linear forms L_0,...,L_3 with det L a unit at the chosen prime p. The Cramer/norm identity and finitely many polynomial factorizations prove

       (tau_n^2:tau_(n+1)tau_(n-1):tau_(n+2)tau_(n-2):tau_(n+3)tau_(n-3))
         =(L_0(k):L_1(k):L_2(k):L_3(k)).

3. A finite residue certificate proving that this tuple is primitive at p on every relevant orbit state, and that paired consecutive states admit unit-pivot forward and inverse recurrence charts.
4. An explicit return, possibly composed with a torsion translation, which reduces to the identity on the fixed invariant surface. This is proved as an algebraic group-law identity, with the finite table used to verify chart regularity.
5. Completed-orbit coverage obtained by explicit descent and local saturation as above, followed by finite leading-term, symmetry, or difference-root certificates for its theta markers.

Then the proposed finite rational-point list is complete whenever it attains the resulting local zero bound. Every homogeneous rational marker and primitive denominator condition transported through L has the same validity and the same p-adic valuations as its coordinate expression on the invariant surface.

Proof. The invertible primitive coordinate map transports points, markers, and their vanishing orders. Pairing consecutive Kummer coordinates recovers a smooth local chart even when one component is a two-torsion node, provided G is not two-torsion modulo p. The unit pivots make every required recurrence and inverse integral analytic on that chart. The exact return identity gives T=I+pK there. Local saturation covers the rational classes by the certified completed orbits; the difference lemmas isolate their possible theta intersections. This proves completeness. The denominator assertion follows by the same invertible change of primitive coordinates.

The scalar gauge tau_n -> A B^n tau_n multiplies every centered product by A^2 B^(2n). It therefore cancels in the projective recurrence. The quadratic exponent in the iterated gauge is still present in a scalar lift, but it cannot introduce or remove a theta zero in the primitive projective state.

The example in Parts I–II supplies every hypothesis, including the singular residue charts. Thus this is now a method card backed by an end-to-end genus-2 evaluation.

TARGET, deliberately separate: prove that an arbitrary scalar Somos-8 state with these specialized invariants admits a single integral gauged-return chart through all zero-bearing windows. The present proof supplies an atlas on the fixed geometric invariant surface, which is sufficient for the evaluation. It does not supply a smooth return on the whole eight-dimensional ambient scalar recurrence space. The Laurent phenomenon alone supplies neither that regularity nor a primitive-denominator theorem.

### V.4. The separation theorem and its remaining arithmetic input

The Q2 construction isolates a different reusable object: a simultaneous approximation lattice with an exact determinant. The object consists of the integer weight formula, the polynomial matrix M_N, its determinant C_N(w-1)^(3N), its common denominator after specialization, and the uniform error integral. Each piece is proved in Part IV.

For the Fibonacci cover, the minimal useful target is the pair Z,Z^2. A full degree-four power basis would use three simultaneous errors and force Q>=E^3 by the determinant estimate, losing the strict quartic improvement. Two errors allow the interval

    E^2<=Q<E^3.

This pinpoints the missing lemma:

TARGET FIB-HP. For the single quartic form

    F(u,w)=19u^4-54u^3w+29u^2w^2+6uw^3-w^4,

produce an explicitly certified common-denominator approximation system for the three-dimensional span of 1,Z,Z^2, with nonzero three-by-three determinant, constants C_Q,C_E, and rates E>1, Q<E^3, covering the four roots of

    beta=(3+4Z+3Z^2)/(i(Z^2-1)), Z^4=(2-4i)/(2+4i),

or their exactly transported seed presentations. All coefficient and error prefactors must be retained. This one lemma gives a finite elementary denominator bound; continued fractions and the reverse-cover tests then finish the evaluation.

The construction in Part IV proves FIB-HP under an explicit sufficient seed inequality. It does not prove that the fixed field has such a seed. The obstruction in Part III explains why independently approximating two functions and multiplying denominators cannot fill this gap with the recorded rates.

BELIEF: a careful arithmetic normalization of a genuinely joint system is a better next direction than enlarging the unit tower. The reason is concrete: the cover already has one fixed quartic form, while the needed improvement is a quantitative comparison of Q and E, not another unverified unit-coverage assertion. This is a research judgment, not a theorem that joint Padé must succeed.

def trim(p):
    p = list(map(Q, p))
    while p and p[-1] == 0:
        p.pop()
    return p


def add(a, b):
    c = [Q(0)] * max(len(a), len(b))
    for i, x in enumerate(a): c[i] += x
    for i, x in enumerate(b): c[i] += x
    return trim(c)


def scale(a, s): return trim([x*s for x in a])


def sub(a, b): return add(a, scale(b, -1))


def mul(a, b):
    c = [Q(0)] * max(0, len(a)+len(b)-1)
    for i, x in enumerate(a):
        for j, y in enumerate(b): c[i+j] += x*y
    return trim(c)


def divmodp(a, b):
    a = trim(a); b = trim(b)
    assert b
    q = [Q(0)] * max(0, len(a)-len(b)+1)
    while len(a) >= len(b):
        i = len(a)-len(b); z = a[-1]/b[-1]; q[i] = z
        a = sub(a, [Q(0)]*i+scale(b,z))
    return trim(q), a


def quotient(a, b):
    q, r = divmodp(a, b)
    assert not r
    return q


def rem(a, b): return divmodp(a, b)[1]


def xgcd(a, b):
    a, b = trim(a), trim(b)
    s0, s1, t0, t1 = [Q(1)], [], [], [Q(1)]
    while b:
        q,r=divmodp(a,b)
        a,b=b,r
        s0,s1=s1,sub(s0,mul(q,s1))
        t0,t1=t1,sub(t0,mul(q,t1))
    z=1/a[-1]
    return scale(a,z),scale(s0,z),scale(t0,z)


def jac_add(D, E):
    u1,v1=D;u2,v2=E
    e,s1,s2=xgcd(u1,u2)
    d,c1,c2=xgcd(e,add(v1,v2))
    h1,h2=mul(c1,s1),mul(c1,s2)
    u=quotient(mul(u1,u2),mul(d,d))
    v=rem(quotient(add(add(mul(mul(h1,u1),v2),
                               mul(mul(h2,u2),v1)),
                           mul(c2,add(mul(v1,v2),F))),d),u)
    while len(u)>3:
        u=quotient(sub(F,mul(v,v)),u)
        u=scale(u,1/u[-1])
        v=rem(scale(v,-1),u)
    assert not rem(sub(F,mul(v,v)),u)
    return u,v


def evaluate(a, x):
    z=Q(0)
    for c in reversed(a):z=z*x+c
    return z


def determinant(A):
    if not A:return Q(1)
    A=[list(map(Q,row)) for row in A]; result=Q(1)
    for k in range(len(A)):
        pivot=next((i for i in range(k,len(A)) if A[i][k]),None)
        if pivot is None:return Q(0)
        if pivot!=k:A[k],A[pivot]=A[pivot],A[k];result=-result
        v=A[k][k];result*=v
        for i in range(k+1,len(A)):
            r=A[i][k]/v
            for j in range(k+1,len(A)):A[i][j]-=r*A[k][j]
    return result

def cantor_division(n, b):
    if n<0:return -cantor_division(-n,b)

def coset_jet(n, S, b):
    """Canonical pole-ordered determinant for nG+sum W_s in Theta."""
    assert n>=3 and len(S)<=2
    g=[Q(1)]
    for a in S:g=mul(g,[3-a,1])
    bound=n+len(S)+1
    basis=[]
    j=0
    while 2*(len(S)+j)<=bound:
        basis.append((2*(len(S)+j), [Q(0)]*j+g))
        j+=1

        basis.append((5+2*j,[Q(0)]*j+b[:n-j]))
        j+=1
    basis.sort()
    assert len(basis)==n

                         for _,row in basis] for i in range(n)])

"""P07 joint Hermite--Pade certificate (Python standard library only).

Checks the finite algebra in the all-N theorem in answers/P07.md.
The all-N integrality, determinant, and analytic bounds are proved there;
finite checks are deliberately not substituted for that proof.

from fractions import Fraction as Q
from math import factorial, comb, prod
from itertools import permutations


def v2(n):
    out = 0
    while n and n % 2 == 0:
        n //= 2
        out += 1
    return out


def trim(a):
    a = list(a)
    while a and not a[-1]: a.pop()
    return a


def add(a, b):
    out = [0] * max(len(a), len(b))
    for i, x in enumerate(a): out[i] += x
    for i, x in enumerate(b): out[i] += x
    return trim(out)


def scale(a, k): return trim([k*x for x in a])


def mul(a, b):
    out = [0] * max(0, len(a) + len(b) - 1)
    for i, x in enumerate(a):
        for j, y in enumerate(b): out[i+j] += x*y
    return trim(out)


def sign(p):
    return (-1) ** sum(p[i] > p[j] for i in range(len(p)) for j in range(i+1, len(p)))


def det3poly(A):
    result = []
    for p in permutations(range(3)):
        term = [sign(p)]
        for i in range(3): term = mul(term, A[i][p[i]])
        result = add(result, term)
    return result


def setup(N):
    nodes = [4*k+i for k in range(N+1) for i in range(3)]
    D = factorial(4*N+2) * 2**v2(factorial(N)) // factorial(N)
    b = {l: Q(D, prod(l-j for j in nodes if j != l)) for l in nodes}
    assert all(x.denominator == 1 for x in b.values())

    A = [[[b[4*k+i]*(4*k+i)**r for k in range(N+1)] for i in range(3)] for r in range(3)]
    return nodes, D, b, A


def gaussian_mul(z, w):
    return z[0]*w[0]-z[1]*w[1], z[0]*w[1]+z[1]*w[0]


def gaussian_add(z, w): return z[0]+w[0], z[1]+w[1]


def gaussian_power(z, n):
    out = (1, 0)
    for _ in range(n): out = gaussian_mul(out, z)
    return out


def gaussian_scale(z, a): return z[0]*a, z[1]*a


def gaussian_det(A):
    out = (0, 0)
    for p in permutations(range(3)):
        term = (sign(p), 0)
        for i in range(3): term = gaussian_mul(term, A[i][p[i]])
        out = gaussian_add(out, term)
    return out


def verify(N):

                    ratio *= (k+alpha-N)/(k+alpha+1)

    assert sum(abs(x) for x in b.values()) <= 4 * 128**N

                    gaussian_power(V, k), gaussian_power(U, N-k)), b[4*k+i]*(4*k+i)**r))
            row.append(term)
        B.append(row)
    assert gaussian_det(B) == gaussian_scale(gaussian_power((0, -4), 3*N), C)
    assert gaussian_det(B) != (0, 0)
