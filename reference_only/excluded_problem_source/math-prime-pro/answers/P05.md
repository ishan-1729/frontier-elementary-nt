## 0. Results and the change to the programme

The most important question has a complete elementary answer for Thomas's fixed parameter a=3. The equation

    |x^3-2x^2 y-5xy^2-y^3|=1

has exactly twelve integer solutions. Section 1 proves this with an exact change of presentation, a fully derived binomial Pade certificate, an explicit height bound, and 57 certified continued-fraction entries. The proof does not assume a unit parametrization or a previously computed rank. The solution list is classical; the purpose of this evaluation is a complete proof within the programme's permitted methods.

The useful change of presentation is

    G_2389(-2x+7y,9x+2y)=67^3 G_2(x,y),
    G_t(x,y)=x^3-t x^2 y-(t+3)xy^2-y^3.

The larger parameter gives a sufficiently strong separator even though its right-hand side has become 67^3. A fixed equation only needs a finite height bound. It need not meet the stronger inequalities that eliminate every nontrivial solution in an entire parametric family at once. This is a useful distinction when choosing a ghost presentation.

## 1. Q1: a complete fixed cubic by changing its presentation

### 1.0 Main result and new mechanism

PROVED, with the exact finite certificate in [P05_fixed_cubic.py](../certificates/P05_fixed_cubic.py).

For all integers x,y, the equation

    |x^3 - 2x^2 y - 5xy^2 - y^3| = 1

has exactly the twelve solutions

    (-9,7), (-7,-2), (-2,9), (-1,0), (-1,1), (0,-1),
    (0,1), (1,-1), (1,0), (2,-9), (7,2), (9,-7).

This is Thomas's a=3 equation, not a substitute easy equation. The proof uses neither Baker bounds nor a unit theorem nor Mordell–Weil theory nor a class group. It consists of one polynomial identity, an elementary binomial Padé construction with a beta-integral remainder, a determinant inequality, and 57 certified continued-fraction entries. The only finite loop not involving those 57 entries checks Y<=503 and -Y/2<X<=Y.

The mechanism is that a bad-looking generator can have a much better Padé generator in the same cubic field. For this equation the generator change is unusually small:

    G_t(x,y) = x^3-t x^2y-(t+3)xy^2-y^3,
    M(x,y) = (-2x+7y, 9x+2y),

and direct expansion gives

    G_2389(M(x,y)) = 67^3 G_2(x,y).                       (1)

Thus the small-parameter equation transfers to the large parameter a'=2390, with a fixed right-hand side 67^3=300763. One does not need the large-parameter theorem to exclude every nontrivial solution at a'=2390. One only needs kappa<2, which gives an effective finite height bound for this fixed right-hand side. The remaining certificate is short.

The field coincidence behind (1) is recorded in Akinari Hoshi, *On correspondence between solutions of a family of cubic Thue equations and isomorphism classes of the simplest cubic fields*, arXiv:0810.3374, Theorem 1.4 and Table 1, https://arxiv.org/pdf/0810.3374 . Hoshi's completeness results use stronger external inputs. NONE of them is used here: (1) is checked directly. The known solution list can be found in the same paper, introduction; it is independently certified below.

The proof is new to this programme, not a claim that the classical fixed equation or its solution list is new.

### 1.1. A general elementary transfer theorem

PROVED. Suppose F and G are irreducible binary cubic forms over Q and M is a rational invertible 2 by 2 matrix satisfying

    G(M(x,y)) = c F(x,y),       c != 0.

After clearing the denominators of M and c, integral solutions of F(x,y)=h map into an explicitly given integer lattice and satisfy G(X,Y)=H for an explicit fixed integer H. Any explicit irrationality estimate of exponent strictly less than 3 for the relevant real roots of G yields an explicit height bound for these transferred solutions, provided the standard norm-factor upper bound is made on finitely many real cones. A finite exact search, for example by continued fractions, then completes the problem.

There is a special cubic reason to search for this. If K is any cubic field and theta,eta are two nonrational elements, then eta is a rational fractional linear function of theta. Indeed the four elements theta*eta, eta, theta,1 are Q-linearly dependent. A nonzero dependence gives

    (c theta+d) eta = a theta+b.

The denominator is nonzero, since theta is irrational. The determinant ad-bc is nonzero, since otherwise eta would be rational. Thus

    eta=(a theta+b)/(c theta+d),        ad-bc != 0.

Taking the products over the three embeddings gives the corresponding identity between binary norm forms. This argument is only dimension-three linear algebra; it does not use a theorem about units or ideals.

This is not a universal theorem that every cubic field possesses a useful hypergeometric generator. The theorem transports a separator once such a generator is found. The hard search is for an explicitly certifiable generator with approximation exponent below the Thue threshold. For Thomas a=3, (1) supplies one.

### 1.2. The Padé certificate, proved for every a>=29

This section independently reconstructs the reported certificate and proves that its bounds are valid at a=2390. No extension of an unproved a>=4001 hypothesis is needed.

Fix an integer a>=29. Put

    f_a(z)=z^3-(a-1)z^2-(a+2)z-1,
    F_a(x,y)=y^3 f_a(x/y),
    omega=(-1+sqrt(-3))/2,
    s=sqrt(-3)=1+2 omega,
    U=a+2+3 omega=(a+1/2)+(3/2)s,
    w=Ubar/U,
    z=w-1=(Ubar-U)/U=-3s/U,
    alpha=1/3.

The bar denotes complex conjugation, not any arithmetic-field operation that requires ideals.

Let theta be the positive root of f_a. We have theta>a, because f_a(a)=-2a-1<0 and f_a tends to +infinity. The other two roots are

    beta=-1/(theta+1),
    gamma=-(theta+1)/theta.

These formulas follow by substitution into f_a; they are distinct and give all three roots. In particular

    -1/2<beta<0,       gamma<-1.

For j>=0 define the polynomials

    P_j(z)=sum_(i=0)^j binom(j-alpha,i) binom(2j-i,j) z^i,
    Q_j(z)=sum_(i=0)^j binom(j+alpha,i) binom(2j-i,j) z^i.

The generalized binomial coefficients are finite products divided by i!, with the empty product equal to 1. Define

    A_j=U^j P_j(z)=q_j-p_j omega.                         (2)

We will prove that p_j,q_j are integers and satisfy

    |q_j| <= 2(5a)^j,
    |q_j beta-p_j| <= (3/a)(a/9)^(-j),                  (3)

and that consecutive cross determinants are nonzero.

#### 1.2.1 The two finite identities and the integral remainder

For any j>=0 and for |z|<1, with the binomial-series branch of (1+z)^alpha, put

    c_j=alpha product_(r=1)^j (1-alpha^2/r^2).

Then

    Q_j(z)=(1+z)^j P_j(-z/(1+z)),                       (4)

and

    (1+z)^alpha P_j(z)-Q_j(z)
      = c_j z^(2j+1)
        integral_0^1 t^j(1-t)^j(1+zt)^(alpha-j-1) dt.  (5)

Here c_j>0 and c_j<=1/3.

For completeness, both identities have an elementary finite derivation. Put v=1+z. In the integral on the right of (5), substitute x=1+zt. After multiplication by z^(2j+1), the integral becomes

    integral_1^v (x-1)^j(v-x)^j x^(alpha-j-1) dx.

This is an integral of a finite polynomial times a real power, with the power defined by its convergent binomial series along the segment. Expand the two polynomial factors. Integrate each monomial. The elementary partial-fraction identity

    sum_(r=0)^j (-1)^r binom(j,r)/(b+r)
       = j!/[b(b+1)...(b+j)]

follows either by clearing the denominator and comparing residues, or by integrating t^(b-1)(1-t)^j first for b>0 and then clearing denominators. It shows that the coefficient of v^(alpha+r), after multiplication by c_j, is

    binom(j-alpha,r) binom(j+alpha,j-r),   0<=r<=j.

The coefficients at the lower endpoint are these same numbers in reverse order. Consequently c_j times the transformed integral equals

    v^alpha sum_(r=0)^j binom(j-alpha,r)binom(j+alpha,j-r)v^r
      - v^j sum_(r=0)^j binom(j-alpha,r)binom(j+alpha,j-r)v^(-r).

To see that the first polynomial is P_j(v-1), expand v^r=(1+z)^r. Its coefficient of z^i is

    sum_(r=i)^j binom(j-alpha,r)binom(r,i)binom(j+alpha,j-r)
      = binom(j-alpha,i)
        sum_(h=0)^(j-i) binom(j-alpha-i,h)binom(j+alpha,j-i-h)
      = binom(j-alpha,i)binom(2j-i,j).

The last equality is the binomial convolution, obtained by multiplying the binomial series for (1+x)^(j-alpha-i) and (1+x)^(j+alpha). Reversing the coefficients changes alpha to -alpha and gives Q_j. This proves (4) and (5), including the exact constant. All these calculations take place in an absolutely convergent power series for |z|<1; no asymptotic approximation is being substituted for an identity.

#### 1.2.2 Integrality, including the prime 3

For each i the coefficient multiplying U^(j-i) in A_j is an integer binomial factor times

    binom(j-1/3,i)(-3s)^i
      = (-s)^i product_(r=0)^(i-1)(3j-1-3r)/i!.

For a rational prime ell!=3, every block of ell^e consecutive factors in the numerator product contains a multiple of ell^e, because 3 is invertible modulo ell^e. Therefore that product has ell-adic valuation at least

    sum_(e>=1) floor(i/ell^e)=v_ell(i!).

For ell=3, the numerator product has no factor 3, but s^2=-3 implies that s^i is divisible in Z[omega] by 3^floor(i/2). On the other hand

    v_3(i!)=sum_(e>=1)floor(i/3^e)<i/2

for i>0, hence v_3(i!)<=floor(i/2). The factorial denominator therefore divides the numerator in Z[omega]. This includes ell=2 and every higher prime. Thus A_j belongs to Z[omega], and (2) defines integers p_j,q_j.

#### 1.2.3 The root and branch normalization

Direct polynomial expansion gives

    U(x-omega y)^3-Ubar(x-omega^2 y)^3=3s F_a(x,y).

At x=beta,y=1 this implies

    ((beta-omega)/(beta-omega^2))^3=w.

Since -1/2<beta<0 and U has positive real and imaginary parts, the correct branch is

    (beta-omega)/(beta-omega^2)=omega^2 W,
    W=w^(1/3),

where W is the branch near 1. Indeed the argument of the left-hand side is between -pi and -2pi/3; after division by omega^2 its argument is between -pi/3 and 0. Its cube is w, whose argument is -2 arg(U), and the asserted branch follows. Here |z|=3sqrt(3)/|U|<1, so the series and integral from (5) are valid.

Conjugating (2) and using (4) gives

    Abar_j=U^j Q_j(z).

A direct substitution of A_j=q_j-p_j omega yields

    (1-omega^2)(q_j beta-p_j)
       = omega^2(beta-omega^2)(W A_j-Abar_j).             (6)

Moreover |1-omega^2|=sqrt(3) and

    |beta-omega^2|^2=beta^2+beta+1<=1.

Thus the complex remainder gives exactly an approximation to beta, with no hidden change of root.

#### 1.2.4 Explicit bounds

Write L=a+1/2, so |U|^2=L^2+27/4. For 0<=t<=1,

    |1+zt|=|(1-t)U+t Ubar|/|U|>=L/|U|.

Using (5), c_j<=1/3, |Ubar-U|=3sqrt(3), and t(1-t)<=1/4, we obtain

    |U|^j |W P_j(z)-Q_j(z)|
      <= sqrt(3)/L * (27/(4L))^j.

For clarity, before using |U|>=L the prefactor is

    sqrt(3) |U|^(-1/3) L^(-2/3),

which is at most sqrt(3)/L. Equation (6) now gives the slightly stronger bound

    |q_j beta-p_j| <= 1/L * (27/(4L))^j.                (7)

Since 1/L<=3/a and 27/(4L)<=9/a, this implies the error estimate in (3).

For the size estimate, 0<binom(j-1/3,i)<=binom(j,i) for 0<=i<=j, and binom(2j-i,j)<=4^j. Hence

    |A_j|<= [4(|U|+3sqrt(3))]^j.

For a>=29, |U|<a+1, 3sqrt(3)<6, and

    4(|U|+3sqrt(3))<4(a+7)<5a.

Finally q_j=Re(A_j)+Im(A_j)/sqrt(3), so |q_j|<=2|A_j|. This proves (3) for every a>=29.

#### 1.2.5 The exact nonzero consecutive determinant

The polynomial

    P_j Q_(j+1)-P_(j+1)Q_j

has degree at most 2j+1. By (5) it vanishes to order 2j+1 at z=0. Its leading coefficient is

    d_j=(2j+2) alpha product_(r=1)^j(r^2-alpha^2)/(j+1)!^2 >0.

Indeed the leading term of the remainder in (5) is

    alpha product_(r=1)^j(r^2-alpha^2)/(2j+1)! * z^(2j+1),

and P_(j+1)(0)=binom(2j+2,j+1). Therefore

    P_j Q_(j+1)-P_(j+1)Q_j=d_j z^(2j+1).

Multiplying by U^(2j+1), using Ubar-U=-3s and s^2=-3, and then writing A_j=q_j-p_j omega gives

    p_j q_(j+1)-p_(j+1)q_j = -d_j(-3)^(3j+1) != 0.     (8)

The sign is immaterial; this convention matches A_j=q_j-p_j omega. The expression is an integer because the left-hand side is an integer. No unproved assertion about the absence of common factors is needed.

### 1.3. The elementary determinant inequality, retaining the small prefactor

PROVED. Suppose real beta and integer pairs (p_j,q_j), j>=0, satisfy consecutive nonzero cross determinants and

    |q_j|<=C_Q Q^j,        |q_j beta-p_j|<=C_E E^(-j),

where C_Q,C_E>0 and Q,E>1. Set

    kappa=log(Q)/log(E),
    K=2 C_Q Q^2 (2C_E)^kappa.

For integers p,q with q>0 and 2C_E q>=1,

    |beta-p/q| >= 1/[K q^(1+kappa)].                    (9)

Proof. Choose j=ceil(log(2C_E q)/log(E)). At least one of q p_j-p q_j and q p_(j+1)-p q_(j+1) is nonzero, by the cross determinant. For that index l in {j,j+1},

    1 <= |q_l(q beta-p)-q(q_l beta-p_l)|
      <= |q_l| |q beta-p|+1/2.

Thus |q beta-p|>=1/(2 C_Q Q^(j+1)). Since j+1<=2+log(2C_E q)/log(E), (9) follows. The pair p,q need not be primitive. Nor does the proof need a separate assertion that every q_j is nonzero: the selected q_l cannot vanish, by the displayed inequality.

For the certificate above,

    C_Q=2, Q=5a, C_E=3/a, E=a/9,
    kappa=log(5a)/log(a/9).

For a=2390,

    a^3=13651919000 > 625*9^7=2989355625,

so kappa<7/4. Also Q/E=45>1, hence kappa>1. Because 6/a<1,

    K=4(5a)^2(6/a)^kappa < 600a.                       (10)

This is the useful quantitative distinction between a finite height bound and the stronger uniform theorem that excludes all nontrivial solutions immediately. Here a'=2390 is enough.

### 1.4. Cone coverage, including zero coordinates

Let

    R(x,y)=(y,-x-y).

Direct expansion gives R^3=I and G_t(R(x,y))=G_t(x,y). Simultaneous negation changes the sign of G_t.

Every nonzero integer pair can be sent by one of the six maps +/-R^j into

    Y>0,       -Y/2<X<=Y.                              (11)

Here is a proof covering all boundaries. Put h=max(|x|,|y|,|x+y|)>0 and choose a signed rotation whose second coordinate is h. For the resulting pair (u,h), both |u|<=h and |u+h|<=h, hence -h<=u<=0. If u>-h/2, it already lies in (11). If u<=-h/2, apply -R^2 to obtain (u+h,-u), where 0<=u+h<=-u and -u>0. This lies in (11). Thus a starting coordinate equal to zero causes no missing case.

For a>=29, let (X,Y) satisfy (11) and |F_a(X,Y)|=H, with H>0. With v=X/Y, the three root factors satisfy

    theta-v > a-1,        v-gamma > 1/2.

Consequently

    0<|v-beta| < 2H/[(a-1)Y^3].                        (12)

This is a bound on the entire cone, rather than a choice of a nearest root made after the fact.

### 1.5. The global height bound for the transformed fixed equation

Take a=2390 and H=67^3=300763. Suppose a normalized pair solves

    |G_2389(X,Y)|=H.

For Y>=504, 2C_E Y=6Y/2390>=1, so (9) applies to p=X,q=Y, regardless of a common divisor. Combining (9), (10) and (12) yields

    Y^(2-kappa) < 2KH/(a-1)
                  <1200aH/(a-1)
                  <2400H.

Because 2-kappa>1/4 and Y>=1,

    Y < (2400H)^4
      =271482974730347081199387033600000000.            (13)

The same bound plainly contains Y<=503. Hence (13) covers every normalized solution.

For Y>=504, the exact integer inequality

    4H=1203052 < 504*2389=1204056

makes (12) strictly smaller than 1/(2Y^2). If X/Y=p/q in lowest terms, then q<=Y and

    |beta-p/q|<1/(2q^2).

The elementary Legendre continued-fraction criterion therefore makes p/q a convergent of beta. That criterion is a standard consequence of the determinant +/-1 of neighboring convergents and their best-approximation property; it uses no Diophantine theorem beyond ordinary continued fractions.

Writing X=dp,Y=dq, homogeneity implies d^3 divides 67^3. Since 67 is prime, d belongs to {1,67}. Thus the only norms that need to be checked among reduced convergents are

    |G_2389(p,q)|=300763       or       |G_2389(p,q)|=1.

In both cases q is below the bound (13).

### 1.7. Relation to the four layers and the cancellation-wall question

Coverage is the explicit invertible linear map M, together with its image-lattice congruences and the finite signed rotation cover. It does not require coverage of the whole unit group.

Property transport is the exact norm identity (1). It changes the right-hand side by the fixed cube 67^3 and retains the integer lattice explicitly.

Separation is supplied by the variable-degree binomial approximants in a better generator. Their error decreases quickly enough to give kappa<2, while their consecutive determinants never vanish. This is exactly the arithmetic gap the smooth local germs lacked.

The global cover is one finite height interval, covered by the exact continued-fraction certificate and the small denominator check.

This does not contradict the spectral barrier in P04: the approximants are not two fixed linear observables of powers of one algebraic unit. Their polynomial degree changes with j, and their binomial coefficient identities perform the cancellations. Nor does it claim that finitely many local congruences can eliminate an entire smooth admissible germ.

The general research target is now sharper than “solve a small-parameter Thue equation somehow”:

TARGET: given a fixed binary cubic norm form, search explicitly through rational fractional linear changes of its generator and algebraic-function presentations for one that has a certified Padé exponent kappa<2. Optimize the total constants only far enough to make the remaining continued-fraction certificate practical. In a fixed equation there is no need to preserve the much stronger inequalities required for an immediate uniform six-solution theorem.

BELIEF: this change of generator is a high-value first step before attempting a new p-adic separator, a new cover, or an entirely new descent. The success here depends on a special explicit identity; no claim is made that all rank-two cubic Thue walls can be crossed this way.

### 1.8 Why the successful presentation exists, and why this is not automatic

There is a useful exact identity behind the matrix M. With omega^2+omega+1=0,

    (7-2omega)^3=251-378omega,
    (5+3omega)(251-378omega)=2389-3omega=conjugate(U_2390),
    Norm(7-2omega)=7^2+7*2+2^2=67.

Thus one small, explicitly known algebraic element makes the imaginary coefficient of a cubic power collapse to -3. This is a direct identity, so finding it from a known nontrivial solution causes no circularity in the completeness proof.

More generally, the fractional-linear identity in Section 1.1 is completely explicit at the level of norm forms. If

    eta=(a theta+b)/(c theta+d), ad-bc!=0,
    F_theta(x,y)=Norm(x-y theta),
    F_eta(X,Y)=Norm(X-Y eta),

then

    F_eta(X,Y)
      =F_theta(dX-bY,aY-cX)/Norm(c theta+d).

This follows by writing the numerator of X-Y eta as

    (dX-bY)+(cX-aY)theta.

The norm multiplier and the inverse-image congruences must be retained. The approximation exponent is transported, while its constants can change substantially. A rational fractional-linear change is therefore a useful way to transport an existing separator; it does not create a strong separator without further arithmetic input.

PROVED CONDITIONAL RATE DIAGNOSTIC. Fix a nonzero U in Z[omega], after a fixed integer scaling if necessary. Suppose V ranges over primitive Eisenstein integers, H=|V| tends to infinity, and the chosen sector satisfies

    Re(UV^3) comparable to H^3,
    |UV^3-conjugate(UV^3)| comparable to H^(3-tau).

Here "comparable" means bounded above and below by positive constants independent of H. For tau>3/2, the unmodified binomial construction used above has certified rates, up to fixed factors,

    Q_H comparable to H^3,
    E_H comparable to H^(2tau-3),
    log(Q_H)/log(E_H) -> 3/(2tau-3).

Proof. Repeat the integral estimate with U'=UV^3 and delta=conjugate(U')-U'. The denominator bound has exponential base 4(|U'|+|delta|), and the error bound has reciprocal exponential base 4 Re(U')/|delta|^2. Fixed denominator-clearing factors do not change these powers of H. Substitution gives the asserted limit.

Consequently tau>9/4 gives a certified exponent below 2 eventually; tau<9/4 gives one above 2 eventually; the boundary tau=9/4 depends on constants. Actual angular accuracy comparable to H^-2 gives exponent tending to 3. Ordinary rational approximation at the quadratic scale supplies only this guaranteed rate. It does not exclude exceptional better approximations, and it does not prove that another Pade construction cannot succeed.

Ordinary removal of coefficient content does not alter this diagnostic. For coprime integers a,b,

    (a+bomega)^3=(a^3-3ab^2+b^3)+3ab(a-b)omega.

Its coefficient content is 1 or 3. A common prime other than 3 would divide a, b or a-b, and substitution into the constant coefficient contradicts coprimality. If 3 divides the content, neither a nor b nor a-b is divisible by 3, so the omega coefficient has exactly one factor 3. Multiplication by conjugate(U) then shows that the content of UV^3 divides 3 Norm(U), a fixed integer.

Likewise, dividing U' by its imaginary coefficient can manufacture a large-looking rational Thomas parameter, but its growing denominator must be cleared at every Pade index. This restores the rates just computed. The success at a=3 uses the stronger exact cancellation displayed at the beginning of this section. It is not a universal procedure for replacing any small parameter by a large integral parameter.

The original equation really does have two independent explicit unit directions. If theta is its positive root, theta and theta+1 have inverses

    theta^(-1)=theta^2-2theta-5,
    (theta+1)^(-1)=-theta^2+3theta+2.

Writing L=log(theta), M=log(theta+1), their first two logarithmic coordinates are (L,-M) and (M,L-M). Their determinant is L^2-LM+M^2>0. Their multiplicative independence follows. The proof above crosses this evaluation without needing to prove that these units generate the entire order.

### 1.9 The continued-fraction criterion used by the certificate

PROVED elementary lemma. If alpha is irrational, p/q is reduced with q>0, and

    |alpha-p/q|<1/(2q^2),

then p/q is a regular continued-fraction convergent of alpha.

Here are the details so the finite certificate has no hidden approximation theorem. Write P_n/Q_n for the convergents, with

    P_n Q_(n-1)-P_(n-1) Q_n=(-1)^(n-1).

Choose n with Q_n<=q<Q_(n+1), using the last occurrence if the initial denominators coincide. Put epsilon_n=Q_n alpha-P_n. Consecutive errors have opposite signs, and

    epsilon_(n-1)=-alpha_(n+1) epsilon_n,
    alpha_(n+1)>a_(n+1),

where alpha_(n+1) is the complete quotient. The determinant identity expresses (p,q) uniquely as

    (p,q)=a(P_n,Q_n)+b(P_(n-1),Q_(n-1)), a,b in Z.

If p/q differs from P_n/Q_n, then b!=0. When a,b have opposite signs, or a=0, their error contributions do not cancel, and |q alpha-p|>=|epsilon_n|. They cannot both be negative because q>0. If they are both positive, the denominator bound forces a<=a_(n+1)-1, and

    |q alpha-p|=|b alpha_(n+1)-a| |epsilon_n|>|epsilon_n|.

Thus in every distinct case |epsilon_n|<=|q alpha-p|. Another application of the nonzero integer determinant gives

    1<=|pQ_n-qP_n|
      <=Q_n|q alpha-p|+q|epsilon_n|
      <=2q|q alpha-p|.

This contradicts the assumed strict inequality. The lemma follows. The standard initial conventions P_(-1)=1,Q_(-1)=0 cover the first convergent as well, so a negative initial partial quotient causes no exception.

### 2.1. The exact moment sequence

Write d = u^2 = 4m, with even u >= 4, and X = n + 1/2, T = n(n+1) = X^2 - 1/4. Define

F_u(X) = B_d(X+1/2) - B_d = d S_(d-1)(n).

The polynomial is even in X and divisible by T^2. Define the monic polynomial f_u by

F_u(X) = T^2 f_u(T), deg f_u = 2m - 2.

Here is the elementary justification of the squared factor. The generating function gives B_d(x+1)-B_d(x)=d x^(d-1), B_d'(x)=d B_(d-1)(x), and B_d(1-x)=B_d(x) for even d. Telescoping proves the power-sum identity and the symmetry in X. The series t/(exp(t)-1)+t/2 is even, so B_(d-1)=B_(d-1)(1)=0 for d>=4. Therefore F_u and its derivative vanish at X=1/2 and X=-1/2. Hence (X^2-1/4)^2 divides F_u. Every even polynomial in X is a polynomial in T=X^2-1/4, giving the stated monic f_u. These are polynomial identities over Q and require no arithmetic theorem.

#### 2.1.1 Centered square-root coefficients

Set

A_u(v) = sum_(j=0)^(2m) alpha_j v^j,

alpha_j = binom(d,2j) B_(2j)(1/2) for j < 2m,

alpha_(2m) = B_d(1/2) - B_d.

Thus F_u(X) = X^(4m) A_u(X^-2), with alpha_0 = 1. The unique formal square root with constant term 1 is

B_u(v) = sqrt(A_u(v)) = sum_(j>=0) b_j v^j.

Its exact recurrence is

b_0 = 1,

2 b_j = alpha_j - sum_(i=1)^(j-1) b_i b_(j-i),

where alpha_j = 0 for j > 2m.

The polynomial part of sqrt(F_u(X)) is

q_X(X) = sum_(j=0)^m b_j X^(2m-2j).

The centered raw residual is

sqrt(F_u(X)) - q_X(X) = sum_(k>=1) b_(m+k) X^(-2k).

Therefore the raw residual moments are the **deep tail b_(m+1), b_(m+2), ... of a nonlinear square root**, with m growing as u^2/4. They are not the Bernoulli numbers or Bernoulli polynomial values.

#### 2.1.2 The smaller T-model used in P04

Define

A_T(v) = v^(2m-2) f_u(1/v)

       = (1+v/4)^(2m) A_u(v/(1+v/4)).

The apparent top two terms cancel because F_u is divisible by T^2. Write

sqrt(A_T(v)) = sum_(j>=0) beta_j v^j.

Then

sqrt(f_u(T)) = T^(m-1) sum_(j>=0) beta_j T^-j,

q_T(T) = sum_(j=0)^(m-1) beta_j T^(m-1-j),

sqrt(f_u(T)) - q_T(T) = sum_(j>=0) beta_(m+j) T^(-j-1).

The beta_j are obtained by the same square-root recurrence, this time from the reversed coefficients of f_u. Equivalently,

sqrt(A_T(v)) = (1+v/4)^m B_u(v/(1+v/4)),

beta_j = sum_(r=0)^j b_r binom(m-r,j-r) 4^(-(j-r)),

where generalized integral binomial coefficients are used when m-r is negative.

#### 2.1.3 The integral scale must be stated

At a square solution, w = u |y|/T is rational and w^2 = f_u(T). Let L_f clear the coefficients of f_u and L_q clear the coefficients of q_T. If w = a/b in lowest terms, then b^2 divides L_f. Consequently any positive integer Delta divisible by L_f and L_q makes

z(T) = Delta (w - q_T(T))

an integer at every solution. This is a safe general normalization, requiring no Bernoulli denominator theorem. If the denominator L_f is squarefree, then w itself is an integer and one may take Delta = L_q. Each finite example can certify this by factoring L_f. For u = 4,6,8,10,12,14, the computed L_f below is squarefree.

The exact T-moments for P04 are therefore

mu_j(u) = Delta beta_(m+j), j >= 0,

z(T) = sum_(j>=0) mu_j T^(-j-1).

#### 2.1.4 Centering does not change the Hankel determinants

Write z(X^2-1/4) = sum_(k>=1) a_k X^(-2k). Then

a_(j+1) = sum_(l=0)^j binom(j,l) 4^(-(j-l)) mu_l.

For every s >= 1,

H_s = det(a_(i+j+1))_(0<=i,j<s)

    = det(mu_(i+j))_(0<=i,j<s)

    = Delta^s det(beta_(m+i+j))_(0<=i,j<s).

PROOF. Let P be the s by s lower triangular matrix P_(i,l) = binom(i,l) c^(i-l), c = 1/4. Vandermonde's identity gives the centered Hankel matrix as P H P^t. Since det P = 1, the determinants agree. This is a genuine useful invariant: a shift between T and X^2 costs no Hankel factor. QED.

The exact moment sequence whose product formula is needed is thus beta_(m+j), not B_(2j), B_(2j)(1/2), or their fixed shifts.

### 2.2. What the classical formulas do, and do not, provide

For example the classical Bernoulli identity, in size-s notation, is

det(B_(i+j))_(0<=i,j<s)

= (-1)^(s(s-1)/2) product_(l=1)^(s-1) [l^4/(4(2l-1)(2l+1))]^(s-l).

The same identity holds with B_(i+j)(x), by a binomial change of moments. Dilcher and Jiu derive other product formulas for odd-index Bernoulli polynomials, Euler polynomial sequences, and related linear combinations or derivatives. Al-Salam and Carlitz's 1959 work gives Bernoulli/Euler determinant identities and formal orthogonal polynomials. Those are relevant analogies, not an identification of the present sequence.

The transformations in our case include (1) degree-dependent falling-factorial weights; (2) truncation at a degree depending on u; (3) a nonlinear square root; (4) a shift of starting index by m = u^2/4; (5) integer scaling. Only the final binomial centering transformation has the simple invariant just proved. None of the cited formulas automatically survives the other transformations.

For illustration,

b_1 = alpha_1/2,

b_2 = alpha_2/2 - alpha_1^2/8,

b_3 = alpha_3/2 - alpha_1 alpha_2/4 + alpha_1^3/16.

The mixed terms already prevent treating b_j as a linearly transformed Bernoulli moment sequence without a further identity.

### 2.3. A uniform theorem that can be proved immediately

The generating function gives clean uniform coefficient and derivative estimates. The missing ingredient is not convergence of the original Laurent expansion; it is quantitative cancellation after Hankel reduction, followed by arithmetic elimination of the auxiliary intersections.

#### Theorem 2.A: uniform majorants

Let d = 4m >= 4 and use the above definitions. Then

sum_(j>=1) |b_j| d^(-2j) < 1/7.

Consequently, for real X >= d, the positive square root is well defined and

|sqrt(F_u(X)) - q_X(X)| < d^(2m+2)/(7X^2).

For every nonnegative integer r and X >= 2d,

|(sqrt(F_u)-q_X)^(r)(X)|/r!

< 4 * 2^r * d^(2m+2)/(7 X^(r+2)).

For the T-model put R = 2d^2. Then

sum_(j>=1) |beta_j| R^-j < 1/6.

For T >= R,

|sqrt(f_u(T)) - q_T(T)| < R^m/(6T).

For every r >= 0 and T >= 2R,

|(sqrt(f_u)-q_T)^(r)(T)|/r! < 2^r R^m/(3T^(r+1)).

All these inequalities can be multiplied by the chosen integer scale Delta.

PROOF. Put C(t) = (t/2)/sinh(t/2) = sum c_(2j)t^(2j), where c_(2j) = B_(2j)(1/2)/(2j)!. We have

C(t) = 1/(1+U(t)),

U(t) = sum_(j>=1) t^(2j)/(2^(2j)(2j+1)!).

At t = 1 the first summand is 1/24 and the ratio of each subsequent summand to its predecessor is at most 1/80. Therefore

U(1) <= (1/24)/(1-1/80) = 10/237 < 1/20.

Expanding (1+U)^(-1) as a geometric series and taking coefficientwise absolute values gives

sum_(j>=1) |c_(2j)| <= U(1)/(1-U(1)) < 1/19.

For 2j <= d,

binom(d,2j) |B_(2j)(1/2)| d^(-2j)

= [d(d-1)...(d-2j+1)/d^(2j)] |c_(2j)| <= |c_(2j)|.

The elementary generating-function identity

    t exp(t/2)/(exp(t)-1)
       =2*(t/2)/(exp(t/2)-1)-t/(exp(t)-1)

gives B_d(1/2) = (2^(1-d)-1)B_d. Since d >= 4,

|B_d|/d^d <= (8/7)|c_d|.

Thus the weighted absolute coefficient norm of A_u(v)-1 at v=d^-2 is less than

(1+8/7)/19 = 15/133 < 1/8.

For a series C of norm delta < 1, the binomial expansion of sqrt(1+C) gives a norm bound at most delta/(1-delta), since |binom(1/2,l)| <= 1. Therefore the norm of B_u-1 is less than 1/7. This proves the first assertion.

For X >= d set v=X^-2 <= d^-2. The tail starting at j=m+1 has absolute value at most (v d^2)^(m+1)/7. Multiplying by X^(2m) proves the raw residual estimate.

To bound derivatives, expand the residual at X(1+t). At |t|=1/2 the absolute Taylor majorant is

sum_(k>=1) |b_(m+k)| X^(-2k) 4^k

<= (d^(2m)/7) * (4d^2/X^2)

when X >= 2d. The coefficient of t^r is X^r times the r-th derivative divided by r!. Multiplying the majorant by 2^r gives the asserted derivative bound. This uses only absolutely convergent real power series.

For the T-model, evaluate absolute coefficient norms at rho = 1/(2d^2). To avoid an incorrect norm estimate for composition by a rational function, use the polynomial identity

A_T(v) = sum_(j=0)^(2m) alpha_j v^j (1+v/4)^(2m-j).

Every exponent 2m-j here is nonnegative. Applying the triangle inequality separately to these polynomial terms gives

||A_T-1||_rho <= (1+rho/4)^(2m) [1+sum_(j=1)^(2m) |alpha_j| (rho/(1+rho/4))^j] - 1.

Since rho/(1+rho/4) <= d^-2, this implies

||A_T-1||_rho <= (1+rho/4)^(d/2) (1+1/8) - 1.

Since binom(d/2,j) <= (d/2)^j,

(1+rho/4)^(d/2) <= 1/(1-d rho/8)

= 1/(1-1/(16d)) <= 64/63.

It follows that ||A_T-1||_rho < (9/8)(64/63)-1 = 1/7, and hence ||sqrt(A_T)-1||_rho < 1/6. The T-tail starts at beta_m, giving R^m/(6T). Expanding at T(1+t) and taking |t|=1/2 gives absolute Taylor norm at most R^m/(3T) for T>=2R; the derivative bound follows exactly as above. QED.

#### 2.3.1 Consequences for determinants and denominators

PROVED. For s >= 1, Theorem 2.A yields

|H_s| <= Delta^s s! 6^-s R^(s m+s(s-1)), R = 2d^2.

This follows by expanding the determinant and observing that every permutation has the same sum of moment indices, s m+s(s-1).

Let L clear all coefficients of A_T. Then (4L)^j beta_j is an integer for every j >= 0. Indeed expand sqrt(1+C) in powers of C. For l>=1 the exact identity binom(1/2,l)=(-1)^(l-1) Catalan_(l-1)/2^(2l-1) shows its denominator divides 4^l. Each product of l coefficients of C has denominator dividing L^l, and a contribution to coefficient j has l<=j. Therefore, if H_s != 0,

|H_s| >= Delta^s (4L)^(-s m-s(s-1)).

These lower and upper bounds also bound inverses of finite Hankel matrices by cofactors. If every entry has absolute value <= M_s and H_s != 0, each inverse entry has absolute value at most (s-1)! M_s^(s-1)/|H_s|. They are elementary and uniform but far too coarse to imply an economical global cover. Nonvanishing is an additional hypothesis in this particular inequality, not a conclusion from the majorant.

One can also make the reduced-tail bounds fully explicit. Let P(T)=sum_(j=0)^s p_j T^j be a Padé denominator, and suppose exact elimination has made the first L-1 negative-power coefficients of P(T)Z(T)-Q(T) vanish. Here Z(T)=Delta(sqrt(f_u(T))-q_T(T)). The coefficient c_l of T^-l satisfies

|c_l| <= C_P R^l,

C_P = (Delta R^(m-1)/6) sum_(j=0)^s |p_j| R^j.

Consequently for T>R,

|P(T)Z(T)-Q(T)| <= C_P (R/T)^L/(1-R/T).

For T>2R, the same absolute-Taylor argument bounds its r-th derivative divided by r! by

2^r T^-r C_P (2R/T)^L/(1-2R/T).

These estimates apply absolute values **after** the exact low-order cancellations. They give a completely effective uniform fallback once the nonzero normal indices are found. What remains missing is a sharp enough growing-index bound to make the resulting cover useful, and the arithmetic root exclusion discussed below; it is not an abstract inability to bound a finite inverse matrix or its tail.

#### 2.3.2 Fixed coefficient asymptotics do not control the relevant tail

PROVED. For each fixed j, as d tends to infinity through multiples of four,

b_j(d)/d^(2j) tends to [t^(2j)] sqrt((t/2)/sinh(t/2)).

For d>2j, alpha_j/d^(2j) tends to B_(2j)(1/2)/(2j)!; the finite square-root recurrence then proves the claim by induction. An O_j(1/d) error follows from the finite products d(d-1).../d^(2j).

This is not an estimate for the actual moments beta_(m+j), because m=d/4 tends to infinity. An argument that substitutes j=m+j0 into an estimate whose constant depends on j is invalid. ### 2.4. A stronger structural substitute for universal nonvanishing

One need not conjecture H_s != 0 for every s and every u. Vanishing pivots can be skipped, with an explicit degree bound on the gap.

#### Theorem 2.B: polynomial-quadratic Padé defect bound

Let f(T) be a monic nonsquare polynomial over Q of degree 2r, with r>=1. Let

Z(T) = sqrt(f(T)) - polynomial_part(sqrt(f(T)))

     = sum_(j>=0) mu_j T^(-j-1).

Put H_0=1 and H_s=det(mu_(i+j))_(0<=i,j<s). Then there is an infinite sequence

0 = S_0 < S_1 < S_2 < ...

such that H_s != 0 exactly when s is one of the S_i, and

1 <= S_(i+1)-S_i <= r.

In particular, among any r consecutive positive indices at least one H_s is nonzero. The statement is unchanged by multiplying Z by a nonzero rational number or by replacing T with T+c.

The gap allowance is necessary even for a smooth genus-2 curve: for f(T)=T^6+1 one has Z(T)=(1/2)T^-3-(1/8)T^-9+..., so H_1=H_2=0 and H_3=-1/8. Thus a general theory of algebraic square-root residuals cannot assume every principal pivot is nonzero.

PROOF. Run the ordinary polynomial continued fraction algorithm on sqrt(f) in Q((T^-1)). Its polynomial part a_0 has degree r. Since sqrt(f) is not rational, the algorithm never terminates. Every subsequent partial quotient a_i has positive degree d_i. Define p_(-2)=0, p_(-1)=1, q_(-2)=1, q_(-1)=0 and p_i=a_i p_(i-1)+p_(i-2), q_i=a_i q_(i-1)+q_(i-2). These identities give reduced convergents p_i/q_i, with q_0=1, and imply directly

deg q_i = S_i = d_1+...+d_i,

deg p_i = S_i+r,

p_i q_(i-1)-p_(i-1)q_i = (-1)^(i-1),

deg(q_i sqrt(f)-p_i) = -S_(i+1).

For the last identity write the exact complete-quotient expression

sqrt(f) = (p_i alpha_(i+1)+p_(i-1))/(q_i alpha_(i+1)+q_(i-1)),

where the complete quotient alpha_(i+1) has degree d_(i+1), and subtract p_i/q_i. Its denominator has degree S_i+d_(i+1)=S_(i+1).

The nonzero polynomial p_i^2-f q_i^2 has degree

(S_i+r)-S_(i+1) = r-d_(i+1).

It is nonzero because f is not a rational square. A polynomial cannot have negative degree. Thus d_(i+1)<=r, proving the gap bound.

To identify the Hankel indices, replace p_i by p_i-a_0 q_i, thereby using the same denominators for Z. A vector (c_0,...,c_(s-1)) lies in the kernel of the size-s Hankel matrix exactly when the polynomial c(T)=sum c_j T^j, of degree<s, admits a polynomial b(T) with

c(T) Z(T)-b(T) = O(T^(-s-1)).

If S_i<s<S_(i+1), choose c=q_i and b=p_i-a_0q_i. This produces a nonzero kernel vector, so H_s=0.

If s=S_i and such a vector existed, compare its fraction b/c with the i-th convergent. The polynomial cross determinant has degree at most

max((s-1)-S_(i+1), s-(s+1)) < 0.

It must be zero. Since the convergent is reduced and its denominator has degree s, its denominator cannot divide a nonzero polynomial c of degree<s. This contradiction proves H_s!=0. QED.

#### Corollary for the Faulhaber family

For every even u>=4 the polynomial f_u is nonsquare. Otherwise its rational square root would make S_(u^2-1)(2)=1+2^(u^2-1) a rational square, hence an integer square. If y^2=1+2^k, k>=3, then (y-1)(y+1)=2^k. These two factors are even integers that are powers of two differing by 2, forcing y-1=2,y+1=4 and k=3. This contradicts k=u^2-1>=15.

Thus Theorem 2.B applies with r=m-1=u^2/4-1. It guarantees adaptive Hankel reduction for every member of the family. Its gap bound grows with u, so it does not give a fixed-dimensional auxiliary space or a uniform number of cells. It removes one unjustified conjectural requirement, rather than solving the whole uniform square problem.

#### Theorem 2.C: adaptive block reduction, including vanishing Hankel pivots

This gives the precise replacement for the all-pivots-nonzero assumption in a T-variable auxiliary space. It is valid for any nonrational proper Laurent series Z(T) over Q; its degree-gap bound is particular to a quadratic polynomial square root.

Let e>=0 and consider the 2e+2 functions

1,T,...,T^e, Z,TZ,...,T^e Z.

Let 0=S_0<S_1<... be the denominator degrees of the polynomial continued-fraction convergents to Z. Normalize each denominator q_i to be monic, and denote its numerator by p_i. Then

q_i Z-p_i = lambda_i T^(-S_(i+1)) + terms of smaller degree,

where lambda_i is a nonzero rational number. Choose I such that S_I<=e<S_(I+1), and write

L=e-S_I+1, d_i=S_(i+1)-S_i.

There is a rational column operation of determinant one that leaves 1,T,...,T^e unchanged and replaces the residual columns by

T^j(q_i Z-p_i), for 0<=i<I and 0<=j<d_i,

together with

T^j(q_I Z-p_I), for 0<=j<L.

All resulting leading powers are distinct. The sum of the exponents of all 2e+2 leading powers is exactly

S(e)=-(e+1)-L(d_I-L) <= -(e+1).

The product of their leading coefficients is

Pi(e)=product_(i=0)^(I-1) lambda_i^(d_i) * lambda_I^L,

because the polynomial columns have leading coefficient1.

If Z=Delta(sqrt(f)-polynomial_part(sqrt(f))) with monic nonsquare f of degree2r, then every d_i<=r. In particular, the deepest negative exponent used is at worst -(e+r).

PROOF. The denominators T^j q_i in the stated blocks are monic with degrees exactly 0,1,...,e, each degree occurring once. Their coefficient matrix relative to 1,T,...,T^e is triangular with diagonal entries1. Replacing Z,TZ,...,T^e Z by these products therefore has determinant1. Since Z is proper, deg p_i<S_i; thus every polynomial T^j p_i has degree at most e-1. Subtracting these polynomial parts uses the existing polynomial columns and also has determinant1.

The full block belonging to i has leading exponents

-S_(i+1), -S_(i+1)+1, ..., -S_i-1.

The completed blocks together give all exponents -1,...,-S_I. The final block has exponents -S_(I+1),...,-S_(I+1)+L-1, all strictly smaller than -S_I. Hence the exponents are distinct. Adding the polynomial exponent sum e(e+1)/2 gives

e(e+1)/2 - S_I(S_I+1)/2 - L S_(I+1)+L(L-1)/2

= -(e+1)-L(d_I-L).

The leading coefficients give Pi(e) directly. The quadratic degree bound is Theorem 2.B. QED.

For consecutive normal indices d_i=1, this recovers the ordinary T-variable Hankel reduction, with S(e)=-(e+1) and Pi(e)=H_(e+1). When some pivots vanish, the exponent weight can improve; the difficulty moves to the nonzero leading coefficients and the tail constants. One must not use the preceding Pi=H identity across a defective block without its appropriate block determinant/sign identity.

On a T-interval of scale U and width W, a verified derivative profile gives the usual determinant estimate

|det| <= C_e |Pi(e)| U^(S(e)) (W/U)^K,

K=(2e+2)(2e+1)/2.

The rational column changes do not change the original integer determinant. In a lattice construction, continue to use the original integer coefficient lattice; do not incorrectly declare coefficients in the reduced rational basis to be integers. Here C_e depends on the polynomial, the chosen columns and their certified derivative profile; it is not a constant depending only on e. The reduced-tail bounds in §2.3.1 make C_e effectively computable, although the resulting estimate may be enormous.

This is a general method-card extension: vanishing Hankel pivots are no longer a failure of auxiliary reduction. They require block reduction. No claim of a uniformly cheap or arithmetically complete cover follows just from the favorable exponent weight.

### 2.5. What a real uniform auxiliary-cover theorem still needs

The exact determinant identities in P04 apply once the relevant nonzero Hankel pivots, reduced leading coefficients, derivative tails, and interpolation norm K_R are controlled. Four separate statements are required:

1. Quantitative pivot or normal-index control in the growing-index regime beta_(m+j), with the auxiliary degree allowed to depend explicitly on u. Theorem 2.B handles existence of pivots but not their useful size.
2. Bounds on all reduced columns, including the tail after cancellation. Bounds on the original residual do not preserve the cancellation gained by elimination if one simply takes absolute values before eliminating.
3. A certified cover of the relevant (u,n) region, with integer lattice index and congruence gains tracked. Bounds merely for the number of intervals for each fixed u do not reduce the family to finitely many u.
4. Uniform arithmetic elimination of each auxiliary intersection. For A(T)w+B(T)=0 the resulting polynomial B(T)^2-A(T)^2 f_u(T) has degree growing with u. The inequality that forces the auxiliary to vanish does not show that this intersection has no integer points.

A closed formula for H_s would address part of (1). It would not by itself prove (2)-(4). Even a cell count bounded independently of u would mean an infinite family of finitely many certification problems, unless the coefficients, tail inequalities, and root elimination were proved by a single symbolic argument valid for all u. This logical distinction is essential.

There is also a separate region n+1/2 < u^2, outside the uniform Laurent domain proved above. Its size grows with u. The coefficient estimates do not address that region merely by making u larger. A separate k-direction or arithmetic separator is still needed there.

As a tiny uniform example, n=2 is excluded by the factorization above. Moreover for k>=4 and k=3 mod4, reducing modulo16 shows S_k(n) is 12 mod16 whenever n=3 or4 mod8; thus those n are excluded. Here even summands vanish modulo16, odd summands have the same residue as their cubes, and a full period of 16 has sum0. This elementary sieve covers some small-n classes but leaves unbounded admissible classes.

### 3.3. Explicit halving, sign changes, and the kernel

For any split monic quintic f(x)=product_i(x-a_i), let P=(a,b) be a nonbranch point. In a splitting extension choose r_i with

  r_i^2=a-a_i,   product_i r_i=-b.

Let e_j be the elementary symmetric functions of the five r_i, and set t=x-a. Define

  U(t)=t^2-e_2 t+e_4,
  E(t)=e_1 t^2-e_3 t+e_5.

PROVED polynomial identity:

  f(a+t)=E(t)^2+t U(t)^2.

Proof: write product_i(z+r_i)=z^5+e_1z^4+e_2z^3+e_3z^2+e_4z+e_5 and put z^2=-t. Its even part is E(t), its odd part is zU(t). Multiplying it by its value at -z gives both f(a+t) and E(t)^2+tU(t)^2.

Consequently the Mumford pair (U,E mod U), with the usual reduction at exceptional values, represents a half of [P-infinity]: the graph y=E(x-a) meets the curve at -P and twice at the divisor U=0.

For a degree-2 divisor P_1+P_2-2infinity, the square roots of delta_i are products r_{i1}r_{i2}. If these products are rational, Galois changes the sign choices for the two halves in matching pairs. The sum of the two half-divisors is rational by the following sign rule, proved next:

  changing an even set S of signs r_i changes the half-divisor by sum_{i in S} W_ai.

This rule is proved by the explicit polynomial identities in section 3.1 below. Together with the elementary exceptional cases (one branch point, two branch points, repeated points, reduced degree 1) this proves ker(delta)=2J. The cases with repeated nonbranch points already have the evident half [P-infinity]. The homomorphism property of delta has the direct resultant proof in section 3.2, including every branch and multiplicity case.

#### 3.3.1 The sign rule has an explicit three-line polynomial certificate

The following identities prove the sign rule directly.

For the two signs to be changed, write their roots r,s; write the other three p,q,h. Set

  A=r+s, B=rs, C=p+q+h, D=pq+ph+qh, E=pqh,
  U_0=(t-B)(t-D), U_1=E-Ct,
  U_+=U_0+A U_1, U_-=U_0-A U_1,
  E_+=-(t-B)U_1+A t(t-D),
  E_-=-(t-B)U_1-A t(t-D),
  q_2=(t-B)^2+A^2 t=(t+r^2)(t+s^2),
  V=q_2(t-D)/A.

The distinctness of the branch roots implies r+s!=0: otherwise r^2=s^2. Direct expansion gives

  V-E_+ = (t-B)U_+/A,
  V+E_- = (t-B)U_-/A,
  f(a+t)-V^2 = -q_2 U_+ U_-/A^2.

The graph y=V meets the divisor for U_+, the two selected branch points, and the negative of the divisor for U_-. Thus the two halves differ by the sum of those two branch-point classes. Every even sign change is a composition of these changes. The same identities apply when one selected r is zero (a branch point P); no division by r is used.

#### 3.3.2 Elementary kernel proof using the sign rule

Here is a proof using the usual uniqueness of reduced Mumford representatives.

First extend delta_i multiplicatively to divisors, giving a point P other than W_i and infinity the value x(P)-a_i, giving W_i the value f'(a_i), and giving infinity the value 1. For closed points take the product over their conjugates. To show this descends to divisor classes it is enough to show it is a square on every principal divisor.

Every rational function is (A(x)+B(x)y)/C(x), with polynomials over the ground field. Polynomial factors in x have paired divisors P+involution(P), including a doubled branch point when appropriate. Their delta_i is a square: away from a_i this is the square of the product of (x(P)-a_i), and at a_i the prescribed f'(a_i) occurs twice. Thus remove C and gcd(A,B). It remains to consider coprime A,B.

Put N(x)=f(x)B(x)^2-A(x)^2 and L=deg N. Its leading coefficient l is a nonzero square when L is odd and the negative of a nonzero square when L is even. Indeed the competing degrees 5+2deg B and 2deg A have opposite parity and cannot cancel. The finite zero divisor of A+By has degree L, with multiplicities. At a nonbranch point its x-values are exactly the roots of N with the same multiplicities; at a branch point x=a_i it occurs precisely when A(a_i)=0, in which case B(a_i)!=0 by coprimality.

If A(a_i)!=0, the product defining delta_i on this zero divisor is

  (-1)^L N(a_i)/l = (-1)^(L+1) A(a_i)^2/l,

which is a square by the stated sign of l. If A(a_i)=0, N has a simple root a_i, since

  N'(a_i)=f'(a_i)B(a_i)^2 !=0.

The product over all other roots is (-1)^(L-1)N'(a_i)/l. Multiplying by the prescribed delta_i(W_i)=f'(a_i) gives

  (-1)^(L-1) f'(a_i)^2 B(a_i)^2/l,

again a square. The pole is L times infinity and contributes 1. This proves delta_i kills every principal divisor, including repeated nonbranch zeros and all branch cases. Hence delta is a homomorphism. For each nonbranch point the product of its five delta coordinates is y^2; at W_i it is f'(a_i)^2. Therefore the image has coordinate product 1.

Now suppose delta(D)=1. For a degree-1 nonbranch divisor, all r_i can be chosen rational, so the explicit half is rational. For a degree-1 branch divisor, take its one r_i=0 and the other four square roots rational; the same formula works.

For two distinct nonbranch support points P_1,P_2, choose rational s_i with s_i^2=(x(P_1)-a_i)(x(P_2)-a_i) and product s_i=y(P_1)y(P_2). Choose r_{i1} with product -y(P_1), and put r_{i2}=s_i/r_{i1}. Under every Galois automorphism the two support points are either fixed or exchanged. The sign changes in the two root lists match coordinate by coordinate and have even parity. The sign rule therefore changes each half by the same 2-torsion class, so their sum is fixed and hence rational.

For one branch support point W_i and one nonbranch rational point P, use the rational s_j for j!=i. The common signs in these four coordinates determine the remaining sign in the second root list by its product condition. Give the zero entry in the first list that same sign; this does not change its value and makes both sign patterns even. The two half-divisor changes again cancel.

For two distinct branch support points W_i,W_j, let d=a_i-a_j. In the two root lists their i-th and j-th entries respectively are zero. In every other coordinate their products are rational square roots of delta_l(D), so their signs match. The remaining needed parity relation follows from

  (r_{i2} r_{j1} product_{l!=i,j} r_{l1})^2
     = -d^2 product_{l!=i,j}(a_i-a_l)
     = delta_i(W_i+W_j).

The right side is a square in the ground field, so the product on the left is in that field, and its Galois signs multiply to +1. This is exactly the condition needed to complete both sign vectors to the same even vector. Again the sum of the halves is rational.

A repeated nonbranch support point is already twice its degree-1 class, and the zero divisor is immediate. These cases exhaust reduced degree at most 2. Conversely every double has trivial delta because delta is a homomorphism into square classes. This proves the kernel statement by square roots, polynomial identities, and rationality of the resulting Mumford coefficients; it uses no class group or Mordell--Weil theorem.

### 3.4. Two versions of coverage: discrete coverage and the weaker span actually needed

#### 3.4.1 PROVED conditional height-descent theorem

Let A be an explicitly represented abelian group with a height H:A->[1,infinity), finite sets of points of bounded height, and a finite set R. Assume:

  (i) A=R+2A;
  (ii) H(2Q)>=c H(Q)^4 for every Q;
  (iii) H(P-R)<=C H(P)^b for every P and R in the finite set,
        with c,C>0 and b<4.

Put B=(C/c)^(1/(4-b)), replacing it by at least 1. If H(P)>B and P=R+2Q, then

  H(Q)<H(P),
  H(Q)<=(C/c)^(1/4) H(P)^(b/4).

If the height takes integer values, descent terminates. If it merely has finite sublevel sets, strict descent cannot continue forever within the initial sublevel set, so termination still follows. Therefore A is generated by R and the finite set {P:H(P)<=B}.

The theorem proves finite generation of this particular group by descent. It does not invoke the general Mordell--Weil theorem.

If a proposed subgroup Gamma contains R and every point of height <=B, it follows that A=Gamma. Proving this stronger statement requires enumerating *all rational lifts* of the low Kummer points and expressing them in Gamma. A rational Kummer point need not lift to J(Q), so both directions of this filter must be handled.

For the present split curve, finite generation plus (HALVE) already gives rank at most 1 by the elementary structure theorem for finitely generated abelian groups: dim_F2 A/2A=5 and dim_F2 A[2]=4. This avoids the low-height enumeration and saturation work if only the p-adic line of rational points is needed. It does not yet prove J(Q)=T+ZG.

#### 3.4.2 Why Kummer quartics give the required inverse-height estimate

Suppose an explicit Kummer model F(k_0,k_1,k_2,k_3)=0 and quartic duplication forms delta_i(k) have been supplied, with delta(kappa(Q))=kappa(2Q). Let k be primitive integral coordinates, H(k)=max|k_i|.

  M k_j^N = sum_i A_ij(k) delta_i(k) + B_j(k) F(k),

where deg A_ij=N-4 and M is a fixed nonzero integer. If g=gcd_i delta_i(k), evaluation shows g divides M: at each prime choose a coordinate k_j which is a unit. Also, choosing |k_j|=H(k) and bounding the coefficient sums of A_ij gives

  max_i |delta_i(k)| >= |M| H(k)^4 / C_A.

After dividing by g, the primitive height satisfies

  H(2Q)>=H(Q)^4/C_A.

#### 3.4.3 PROVED compact-completion coverage theorem: same-prime descent needs no height

Let A be an abelian group inside a compact topological abelian group K, and let L:K->Q_p^g be a continuous homomorphism. Suppose L(T)=0 and

  A = T + {sum_i e_i G_i:0<=e_i<p} + pA.

Then

  L(A) subset sum_i Z_p L(G_i).

Proof: repeatedly choose P_j=t_j+sum_i e_ij G_i+pP_{j+1}. After N steps,

  L(P_0)=sum_i (sum_{j=0}^{N-1} e_ij p^j)L(G_i)+p^N L(P_N).

The image L(K) is bounded by compactness, so the final term tends to zero. The digit sums converge in Z_p.

For an explicitly described Jacobian, take K=J(Q_p) and define L by the formal logarithm on a sufficiently small subgroup, extending it to K by multiplying into that subgroup and dividing by the multiplier. All required power series identities can be checked from the formal addition law. This needs neither finite generation nor height descent.

Consequently (HALVE) alone places all rational logarithms on the Z_2-line generated by G. C has good reduction at 7, and its eight points modulo 7 are

  infinity, (0,0),(1,0),(2,0),(5,0),(6,0),(3,1),(3,-1).

These can be checked by direct substitution. The two rational points P=(3,6) and Q=(10,-120) reduce to the same point. In their residue disc write t=x-3 and choose the square-root branch y(t) in Z_7[[t]] with y(0)=6. Q corresponds to t=7. Put

  I_0=integral_0^7 dt/y(t),
  I_1=integral_0^7 (3+t)dt/y(t),
  lambda=I_1/I_0.

Here v_7(I_0)=1 and lambda is in Z_7 with lambda=3 mod 7, since I_0/7=1/6 mod 7 and I_1-3I_0 is divisible by 49.

The divisor Q-P is -3G-(W_2+W_5). Thus its formal logarithm is a nonzero multiple of log(G), and the differential

  omega=(x-lambda) dx/y

annihilates the rational logarithmic line. The formal-group/logarithm compatibility means that for any two rational points in one residue disc their local integral of omega is zero. This compatibility is a polynomial/power-series identity on explicit Cantor charts, not an invocation of global Coleman integration.


The compatibility with formal logarithms has an elementary addition-law proof. On a generic Cantor addition chart let h(x) be the cubic interpolating polynomial. The six intersections of y=h(x) with the curve have x-coordinates r_i, roots of F(x)=f(x)-h(x)^2. Under an infinitesimal variation of h,

    dr_i/y_i=2 dh(r_i)/F'(r_i).

For a polynomial F of degree6 with distinct roots, partial fractions give

    sum_i R(r_i)/F'(r_i)=0 whenever deg R<=4.

Apply this first to R=dh, of degree at most3, and then to R=x dh, of degree at most4. The sums of dx/y and x dx/y over the intersection divisor both vanish. With the signs in Cantor reduction, these are precisely invariance under addition. Clearing denominators extends the identities across the other smooth charts. Integrating the resulting invariant power series, with zero constant term, gives the formal logarithm and the asserted local integral identity. This supplies the needed compatibility without importing a global Coleman integration theorem.

At a finite Weierstrass residue point a in {0,1,2,5,6}, use y as parameter. The equation gives

  omega=2(x-lambda)dy/f'(x).

Its constant coefficient is a 7-adic unit because a!=3 mod 7 and f'(a) is a unit. On y=7s the local integral, divided by 7, has unit linear coefficient and all higher coefficients divisible by 7. It has exactly one zero in that disc, the known branch point.

At infinity take a standard integral uniformizer t=x^2/y. The expansions start x=t^-2+..., y=t^-5+..., so omega=-2dt+... modulo 7. The same unit-linear argument leaves only infinity.

At either ordinary residue disc x=3 mod 7, use t=x-3. Write

  omega=(c_0+c_1 t+c_2 t^2+...)dt,

where c_0 is divisible by 7, c_1 is a unit, and every c_j is 7-integral. For its local primitive F(t),

  F(7s)=7 c_0 s + 49 c_1 s^2/2
             + sum_{j>=2} 7^(j+1)c_j s^(j+1)/(j+1).

After division by 49 this is an integral restricted series, with unit coefficient of s^2 and all higher coefficients divisible by 7. Indeed j+1-v_7(j+1)>=3 for every j>=2. Strassmann therefore gives at most two zeros in each of these two discs.

There are six unit-linear discs and two quadratic discs, so at most 6+2+2=10 rational points. The ten displayed points attain this bound.

This is already a complete separation proof once coverage of the rational logarithmic line is proved. It also specifies what the tau card must reproduce: six simple local intersections and two discs containing two simple intersections after one further 7-adic subdivision. A brute residue sieve is unnecessary here.

For diagnostic verification, direct finite-field counts give

  #C(F_7)=8, #C(F_49)=46, #J(F_7)=48;
  #C(F_11)=16, #C(F_121)=118, #J(F_11)=176.

The genus-2 count identity is #J(F_p)=(#C(F_p)^2+#C(F_p^2))/2-p, obtainable by counting reduced effective degree-2 divisors. Reduction at these two good primes bounds rational torsion by gcd(48,176)=16, so T is all rational torsion. This also certifies G is not torsion. ### 3.6. Tau transport and the primitive-denominator issue

The correct genus-2 curve condition is *incidence with the theta divisor*. Under P -> [P-infinity], the curve C is Theta in J. In Mumford language its points have reduced degree at most 1. A generic Jacobian point has reduced degree 2. Thus a tau function representing the theta section vanishes at curve points. There is no universal rule saying that integral curve points are indices with tau_n=+/-1.

On the Kummer surface, a trope plane cuts out twice the theta conic. Its pullback vanishes with multiplicity 2 along Theta. Accordingly a Kummer marker can have a quadratic leading term even when the intersection of the orbit with the curve is transverse upstairs. Use a simple local theta marker on the signed Jacobian, or use the second-order lifting card with the actual multiplicity recorded.

For this benchmark G is the image of a single curve point. The natural recurrence is the genus-2 Somos-8/Cantor division-polynomial construction for translations D_0+nG. The relevant primary reference is Braden--Enolskii--Hone, *Bilinear recurrences and addition formulae for hyperelliptic sigma functions*, especially Theorem 2 and the note added in proof:

https://kar.kent.ac.uk/41493/1/0501162v4.pdf

Its algebraic Cantor/Hankel identities can replace the analytic sigma-function derivation in the final proof. The reference does not assert that every arbitrary Somos-8 seed is genus 2; its hypotheses on the curve and translation matter. Likewise a certified unrelated Somos-6/8 recurrence is not automatically a parametrization of this C.

PROVED primitive denominator lemma for monic odd-degree hyperelliptic models: if f is a monic integral polynomial of degree 2g+1 and (x,y) is a rational affine point on y^2=f(x), then

  x=A/B^2, y=C/B^(2g+1),

with A,B,C integers, B>0, gcd(A,B)=gcd(C,B)=1. Indeed, at a prime where v_p(x)<0, the leading term of f(x) has strictly smaller valuation than every other term, so 2v_p(y)=(2g+1)v_p(x); v_p(x) is therefore even. At other primes both coordinates are integral. Integral points are exactly B=1.

For g=2 this is x=A/B^2,y=C/B^5. Transporting B to recurrence coordinates requires a separate gcd/resultant certificate for the rational reconstruction map. The Laurent phenomenon only ensures polynomial/Laurent expressions; it does not prove that a displayed recurrence denominator is primitive, or provide primitive divisors. For the recommended evaluation, the stronger rational-point separation makes an integrality-denominator exclusion unnecessary. The lemma still verifies the property layer and recovers the integral answer immediately.

## 4. The next theorem: descent to a local closure, followed by certified separation

### 4.1 A theorem that needs less than a global integer orbit

PROVED THEOREM. Let p be a prime. Let A be an abelian group embedded in a compact topological abelian group K, and let

    L:K -> Q_p^g

be a continuous homomorphism. Suppose T is a subgroup with L(T)=0, and G_1,...,G_r belong to A. Assume the exhaustive descent identity

    A = T + {e_1 G_1+...+e_r G_r : 0<=e_i<p} + pA.       (D)

Then every point of A lies in the closed set

    W = L^(-1)(Z_p L(G_1)+...+Z_p L(G_r)).               (W)

Suppose further that an explicit finite collection of analytic charts covers the intersection of W with a specified arithmetic solution property. In each chart suppose the transported property is expressed by analytic marker equations and finitely many explicit local witness conditions. If finite lifting/Strassmann certificates show that the common admissible zeros are exactly a specified finite list of global points, that list is the complete solution set.

The conclusion requires neither a height bound nor finite generation of A. It also does not require the map from the displayed Z_p-module to K to be globally injective. Torsion and the finitely many local chart components must be retained in the covering data.

Proof. Starting with P_0 in A, apply (D) successively:

    P_j = t_j + sum_i e_ij G_i + p P_(j+1),
    0<=e_ij<p, t_j in T.

After N substitutions and application of L,

    L(P_0) = sum_i (sum_(j=0)^(N-1) e_ij p^j)L(G_i)
                + p^N L(P_N).

Compactness makes L(K) bounded. Therefore the last term tends to zero. Each digit sum converges in Z_p, giving (W). A finitely generated Z_p-module in Q_p^g is compact and closed, since it is the continuous image of Z_p^r. Every global solution is consequently in the specified finite chart cover. Its transported markers and witnesses satisfy that chart's certified conditions, so it is one of the listed zeros. Conversely the listed global points are checked directly. This proves the theorem.

For an explicit p-adic commutative group, L can be constructed from its convergent formal logarithm on a sufficiently small subgroup U. To extend it, choose an integer N killing the finite quotient K/U and set L(P)=L_U(NP)/N. Independence of N and additivity follow by multiplying into a common smaller subgroup and using the formal addition identity. This is local power-series algebra. It does not use a theorem about the global rank.

The new content relative to the existing lifting cards is the first half of the theorem: an exhaustive descent supplies coverage of a compact analytic closure. The lifting cards then act on a set known to contain every global solution. No unproved identification of the global group with a chosen recurrence orbit is inserted between these steps.

### 4.2 Two limits that must remain explicit

PROVED: matching the prime is essential. Let

    A = Z direct_sum Z[1/2] subset Z_7^2,
    G=(1,0).

Then A={0,G}+2A, because multiplication by 2 is onto the second summand. Yet A is dense in Z_7^2. Its 7-adic closure has dimension 2, and it is not contained in the line through G. Thus a two-descent table alone cannot justify a one-dimensional 7-adic orbit. The theorem gives its correct local span, not a false assertion that every global element is an integer multiple of 1. Accordingly a tau presentation indexed by Z still needs its own saturation and coverage theorem if that exact presentation is used in the final argument.

"""Standard-library verification of the split genus-2 arithmetic table.

This verifies the finite arithmetic, not the geometric interpretation of delta.
"""
from math import prod

ROOTS = [0, 1, 2, 5, 6]


def square_class(z, place):
    assert z != 0
    if place == 0:
        return int(z < 0)
    parity = 0
    while z % place == 0:
        z //= place
        parity ^= 1
    if place == 2:
        # Odd units: (-1)^e 5^f; code is e + 2*f.
        return parity | ({1: 0, 7: 1, 5: 2, 3: 3}[z % 8] << 1)
    return parity | (int(pow(z % place, (place - 1) // 2, place) != 1) << 1)


def encode(values, place):
    width = 1 if place == 0 else 3 if place == 2 else 2
    return sum(square_class(v, place) << (width * i)
               for i, v in enumerate(values))


def insert(basis, value):
    while value:
        pivot = value.bit_length() - 1
        if pivot not in basis:
            basis[pivot] = value
            return True
        value ^= basis[pivot]
    return False


def contains(basis, value):
    while value:
        pivot = value.bit_length() - 1
        if pivot not in basis:
            return False
        value ^= basis[pivot]
    return True


def span(generators):
    result = {0}
    for generator in generators:
        result |= {a ^ generator for a in result}
    return result


torsion = [
    [a-b if a != b else prod(a-c for c in ROOTS if c != a)
     for b in ROOTS]
    for a in ROOTS
]
G = [3-a for a in ROOTS]
extra_2 = [-1-a for a in ROOTS]
assert prod(extra_2) == -252
assert square_class(-252, 2) == 0

local_generators = {

    3: torsion[:3] + [G],

# A global coordinate uses sign, 2, 3, 5. The fifth coordinate equals
# the product of the first four, ensuring that the total product is a square.
global_primes = [-1, 2, 3, 5]
local_columns = {}
for place in local_bases:
    columns = []
    for bit in range(16):
        values = [1] * 5
        values[bit // 4] = global_primes[bit % 4]
        values[4] = global_primes[bit % 4]
        columns.append(encode(values, place))
    local_columns[place] = columns

for candidate in range(1 << 16):
    admissible = True
    for place, basis in local_bases.items():
        image = 0
        for bit in range(16):
            if candidate >> bit & 1:
                image ^= local_columns[place][bit]
        if not contains(basis, image):
            admissible = False
            break
    if admissible:
        intersection.append(candidate)

def global_coordinate_code(value):
    result = int(value < 0)
    value = abs(value)
    for bit, prime in enumerate((2,3,5), start=1):
        while value % prime == 0:
            value //= prime
            result ^= 1 << bit
    assert value == 1
    return result

global_codes = []
for row in torsion[:4]+[G]:
    coordinate_codes = [global_coordinate_code(value) for value in row]
    total = 0
    for code in coordinate_codes:

    assert total == 0
    global_codes.append(sum(code << (4*i) for i,code in enumerate(coordinate_codes[:4])))

def legendre(z, p):
    if z % p == 0:
        return 0
    return 1 if pow(z % p, (p-1)//2, p) == 1 else -1

def trim(coefficients):
    while coefficients and coefficients[-1]==0:
        coefficients.pop()
    return coefficients

def remainder(a,b,p):
    a=trim([v%p for v in a]); b=trim([v%p for v in b])
    while a and len(a)>=len(b):
        multiplier=a[-1]*pow(b[-1],-1,p)%p
        shift=len(a)-len(b)
        for j,value in enumerate(b):
            a[shift+j]=(a[shift+j]-multiplier*value)%p
        trim(a)
    return a

def polynomial_gcd(a,b,p):
    while b:
        a,b=b,remainder(a,b,p)
    return trim(a)
