### Why the quartic approximation threshold is 4

Put

    g(X)=X^4-6X^3-29X^2+54X-19.

Then the equation in Q1 is exactly

    u^4 g(w/u)=1

when u!=0. The case u=0 gives w=+/-1 directly. The four real roots beta_i of g are distinct. On a fixed small interval about beta_i, all three other root factors have fixed positive lower bounds. Consequently every solution in that interval satisfies

    |w/u-beta_i| <= C_i |u|^(-4),

with an explicit C_i obtainable from rational root-isolating intervals. Away from these four intervals, |g| has a positive lower bound on a fixed bounded interval. Also |w/u|<10: for |X|>=10,

    |g(X)| >= |X|^4-6|X|^3-29|X|^2-54|X|-19 >=541>1.

The last inequality follows on dividing by |X|^4 and using |X|>=10. Thus the remaining solutions already have bounded |u|. A lower bound |beta_i-p/q|>=c_i q^(-mu_i) with mu_i<4 gives a height cutoff in the ith root cone. A complete separator proof needs all root cones or an independent cover excluding those left over. Equality mu_i=4 gives no cutoff merely by comparing exponents; its constants would require a separate strict comparison.


## Part I. Relative quadratic structure and the scalar norm-determinant barrier

### I.1. Result and scope

PROVED: the fixed Fibonacci Thue equation has an especially simple quadratic norm form over Q(sqrt(5)). It gives an exact one-dimensional relative binomial Padé system, with a constant alternating determinant and fully explicit archimedean rates.

PROVED OBSTRUCTION: a scalar approximation system with coefficients in a totally real quadratic order, used with the P06 norm-determinant lemma and only one small error at one real place, cannot produce a rational-approximation exponent strictly below four. This holds for every seed and every proved content normalization satisfying the stated hypotheses. The obstruction comes from the integer norm of the approximants' own cross determinants.

Thus the proposed relative quadratic reduction is algebraically valid but does not, by that scalar norm-determinant architecture, cross the quartic threshold. This is not an impossibility theorem for genuinely coupled approximation, for exploiting another relation satisfied by the unknown, or for all elementary methods.

### I.2. Exact relative norm and an elementary unit parametrization

Put

    epsilon=(1+sqrt(5))/2, epsilon'=1-epsilon,
    F=Q(epsilon), O=Z[epsilon], epsilon^2=epsilon+1,
    eta=sqrt(epsilon+2)=sqrt(10+2sqrt(5))/2,
    K=F(eta),
    beta=3epsilon-2eta.

The element beta is the simpler conjugate of the generator in P07. Its polynomial is

    g(X)=X^4-6X^3-29X^2+54X-19.

For integers u,w define

    A=u^2+w^2,
    B=5u^2-6uw,
    H=A+B epsilon.

Relative conjugation fixes epsilon and sends eta to -eta. Direct multiplication gives

    Norm_(K/F)(w-beta u)
      =(w-3epsilon u)^2-4(epsilon+2)u^2
      =w^2+u^2+epsilon(5u^2-6uw)
      =H.

Since epsilon+epsilon'=1 and epsilon epsilon'=-1,

    Norm_(F/Q)(A+B epsilon)=A^2+AB-B^2.

Consequently

    Norm_(K/Q)(w-beta u)
      =A^2+AB-B^2
      =-19u^4+54u^3w-29u^2w^2-6uw^3+w^4
      =-F_Fib(u,w).

Every F_Fib(u,w)=-1 solution therefore gives a unit H of norm one in the explicitly given order O. Its two real values are positive. Indeed A>0, while

    A=(epsilon H'-epsilon' H)/sqrt(5).

If H,H' were both negative, the right side would be negative because epsilon>0 and epsilon'<0. Their product is one, so the only remaining possibility is H,H'>0.

PROVED elementary norm-one unit lemma. Every totally positive H in Z[epsilon] with norm one is epsilon^(2k) for a unique integer k.

Proof. Choose k so that H0=epsilon^(-2k) H satisfies

    1<=H0<epsilon^2.

This remains in O because epsilon^(-1)=epsilon-1. It has norm one, so H0'=1/H0. If H0=a+b epsilon with integers a,b, then

    0 <= b=(H0-H0')/sqrt(5)
      < (epsilon^2-epsilon^(-2))/sqrt(5)=1.

Hence b=0 and H0=1. Uniqueness follows from epsilon>1. This is a direct interval reduction in this particular order; no unit theorem is invoked.

We therefore obtain the exact necessary condition

    u^2+w^2=A_k,
    5u^2-6uw=B_k,
    A_k+B_k epsilon=epsilon^(2k), k in Z.               (R1)

The coefficient recurrence is

    (A_(k+1),B_(k+1))=(A_k+B_k,A_k+2B_k),
    (A_0,B_0)=(1,0).

Its inverse has integer matrix [[2,-1],[-1,1]], so negative indices cause no problem.

#### Why this does not remove the original arithmetic condition

Define Fibonacci numbers for every integer n by F_0=0, F_1=1 and F_(n+1)=F_n+F_(n-1). Then

    epsilon^n=F_n epsilon+F_(n-1),
    F_(-n)=(-1)^(n+1)F_n.

Thus A_k=F_(2k-1), B_k=F_(2k). Set

    s=3u^2+5uw-3w^2.

An exact polynomial identity gives

    s^2=9A^2+5AB-B^2.

On the norm-one locus A^2+AB-B^2=1 this becomes

    s^2=4A(2A+B)+1.

Since 2F_(2k-1)+F_(2k)=L_(2k), where L_n=epsilon^n+epsilon'^n, the elementary product identity

    F_(2k-1)L_(2k)=F_(4k-1)+1

gives

    s^2=4F_(4k-1)+5.                                  (R2)

This is exactly the original Fibonacci square condition after writing s=2m+1. The relative norm has exposed one unit exponent, but the remaining square restriction is still the evaluation to be solved. It has not supplied a new cutoff or an extra independent vanishing marker.

### I.3. An exact relative binomial Padé construction

Put

    theta=epsilon+eta,
    theta_bar=epsilon-eta=-1/theta.

The relation follows from epsilon^2-eta^2=-1. Define A_j,B_j in O by

    A_0=1, B_0=0,
    A_(j+1)=epsilon A_j+(epsilon+2)B_j,
    B_(j+1)=A_j+epsilon B_j.

Then for every j>=0,

    theta^j=A_j+B_j eta,
    theta_bar^j=A_j-B_j eta.

(The A_j,B_j in this section are approximant coefficients, not the norm-one coefficients A_k,B_k in R1.) Set

    q_j=B_j,
    p_j=3epsilon B_j-2A_j.

These belong to O and satisfy the exact error identity

    q_j beta-p_j=2 theta_bar^j=2(-1/theta)^j.           (R3)

Their consecutive determinant is exactly

    p_j q_(j+1)-p_(j+1)q_j=-2(-1)^j.                 (R4)

Proof. The recurrence matrix for (A_j,B_j) has determinant -1. Therefore

    A_jB_(j+1)-A_(j+1)B_j=(-1)^j.

Substitution gives (R4). In particular its norm to Q is always 4 and it never vanishes.

#### This is the elementary square-root Padé system, not just an analogy

For an indeterminate z, write x=sqrt(1+z) and define degree-j polynomials

    P_j(z)=sum_(r=0)^j binom(2j+1,2r)(1+z)^r,
    Q_j(z)=sum_(r=0)^j binom(2j+1,2r+1)(1+z)^r.

The binomial theorem gives

    (1+x)^(2j+1)=P_j(z)+xQ_j(z),
    P_j(z)-xQ_j(z)=(1-x)^(2j+1).

Thus the error vanishes to order 2j+1 at z=0, and these are diagonal Padé approximants to sqrt(1+z). Their exact polynomial cross determinant is

    P_j(z)Q_(j+1)(z)-P_(j+1)(z)Q_j(z)=-2z^(2j+1).     (R5)

For example, this follows by multiplying the two conjugate expressions above; alternatively apply the two-step determinant recurrence to powers of 1+x, whose relative norm is -z.

For our field take z=epsilon^(-2). Then eta/epsilon=sqrt(1+z), and

    A_(2j+1)=epsilon^(2j+1) P_j(epsilon^(-2)),
    B_(2j+1)=epsilon^(2j) Q_j(epsilon^(-2)).

All coefficients remain in O because epsilon is a unit. Hence the odd-index subsequence of (R3) is precisely a one-dimensional binomial construction over the real quadratic base. Its consecutive determinant, with the Padé index j, is

    p_(2j+1)q_(2j+3)-p_(2j+3)q_(2j+1)=4epsilon,

whose rational norm is -16 and in particular is nonzero.

#### Exact growth and error rates at both real places

At the first real embedding put

    Q=E=theta=epsilon+sqrt(epsilon+2)>1,
    C_Q=1/eta, C_E=2.

The closed formula for B_j gives

    |q_j| <= Q^j/eta,
    |q_j beta-p_j| = 2E^(-j).                         (R6)

At the other embedding put

    eta'=sqrt(epsilon'+2),
    B=eta'-epsilon'>1.

There theta'=epsilon'+eta'=1/B, while theta_bar'=-B. Consequently

    |q_j'| <= B^j/eta',
    |p_j'|+|q_j'| <= [2+(3|epsilon'|+1)/eta'] B^j.    (R7)

We also have E>B: indeed Q-B=1+eta-eta'>1. The P06 norm-determinant lemma therefore applies. It gives the explicit rational-approximation exponent

    mu=2[1+log(QB)/log(E/B)]
       =4 log(theta)/(log(theta)-log(B)) > 4.         (R8)

Numerically this is about 7.465807658. The strict inequality is exact because B>1 and theta>B. The decimal is only illustrative.

For completeness, for rational p/q in the interval |p/q-beta|<=1 set M=|beta|+1 and

    C_D=2+(M+3|epsilon'|)/eta',
    kappa=log(QB)/log(E/B),
    K=2 C_Q C_D (QB)^2 (4C_D)^kappa.

The elementary norm argument, using one of the two indices j,j+1, gives

    |beta-p/q| >= 1/(K q^(2+2kappa)), q>=1.           (R9)

Take j>=1 least with (E/B)^j>=4C_D q^2. At one of j,j+1 the O-valued determinant p q_j-q p_j is nonzero by (R4). Its other embedding is at most q C_D B^j, so its first embedding has absolute value at least 1/(q C_D B^j). Half that lower bound absorbs the error term by the choice of j. The remaining term gives (R9), with the displayed ceiling allowance. Approximations outside the fixed interval are harmless after enlarging K to at least one.

The odd-index Padé version has bases Q^2,E^2,B^2 and the same exponent (R8). This construction is completely explicit, but it is weaker than the elementary quartic Liouville exponent and cannot close F_Fib.

### I.4. PROVED obstruction to every scalar real-quadratic norm-determinant separator

#### General totally real coefficient-field theorem

Let F be a totally real number field of degree e, with a specified order O. Choose one real embedding sigma_0. Let theta be a fixed real number. Suppose p_j,q_j in O, for all sufficiently large j, satisfy

    |sigma_0(q_j)| <= C_Q Q^j,
    |sigma_0(q_j)theta-sigma_0(p_j)| <= C_E E^(-j),

and at every other embedding sigma_i,

    |sigma_i(p_j)|+|sigma_i(q_j)| <= C_i B_i^j.

Here all constants and all bases Q,E,B_i are positive. Assume consecutive cross determinants

    D_j=p_j q_(j+1)-p_(j+1)q_j

are nonzero for arbitrarily large j. Put

    B_*=product_(i=1)^(e-1) B_i.

Then necessarily

    E <= Q B_*^2.                                    (R10)

Proof. At sigma_0 the theta terms cancel, and the two error bounds give

    |sigma_0(D_j)|
       <= C_Q C_E (Q+E^(-1))(Q/E)^j.

At sigma_i, the coefficient bounds give

    |sigma_i(D_j)| <= 2 C_i^2 B_i * B_i^(2j).

Since a nonzero element of an order has nonzero integer norm,

    1 <= |Norm_(F/Q)(D_j)|
       <= C (Q B_*^2/E)^j

with C independent of j. If E>Q B_*^2 the right side tends to zero along the nonzero determinants, a contradiction. This proves (R10). The same proof permits determinants between indices separated by any fixed bounded number of steps.

Now additionally assume that every sufficiently large consecutive determinant is nonzero, or that the necessary nonzero determinants occur within a fixed bounded distance of every sufficiently large index. Assume E>B_* so that the P06 norm-determinant argument can be used for rational unknowns p/q in a fixed bounded interval. That argument has exponent

    mu=e[1+log(QB_*)/log(E/B_*)].                     (R11)

Equation (R10) says

    log(E/B_*)<=log(QB_*).

The denominator is positive, so

    mu>=2e.                                          (R12)

For a real quadratic coefficient field e=2, the lower limit is four. The usual exponent-comparison height cutoff for a degree-four Thue equation requires a strict rational-approximation exponent below four. An equality-case argument with separately favorable sharp constants or logarithmic gains would be another calculation, not supplied by this exponent comparison. Thus:

PROVED: no scalar two-approximant construction over a real quadratic order, combined with exactly these separate-embedding norm bounds, can provide that strict improvement. This covers a one-dimensional binomial Padé construction, its primitive content-normalized versions, and any other scalar approximation sequence satisfying the same hypotheses.

This theorem does not say that every conceivable norm argument has exponent at least four. It identifies the information discarded by this particular proof: all other embeddings are bounded by size alone. A coupled construction that obtains another small error or exploits a special relation of the unknown need not satisfy that reduction. For example, if the unknown cross determinants are proved to lie in a known rank-one rational lattice times a controlled factor, a stronger lower bound than the generic field norm may be available. That is additional arithmetic structure and is not excluded by this theorem.

#### Unit balancing is exactly neutral

Suppose the approximants are replaced by

    p_j^new=lambda^j p_j, q_j^new=lambda^j q_j,

where lambda is a unit of O. Put r=|sigma_0(lambda)|. Since the absolute norm of lambda is one, the bases change to

    Q_new=rQ,
    E_new=E/r,
    B_*new=B_*/r.

Therefore both quantities entering (R11) are unchanged:

    Q_new B_*new=QB_*,
    E_new/B_*new=E/B_*.

The exponent is exactly invariant. Concentrating the size into one real embedding by multiplication by a base-field unit cannot beat the barrier.

For multiplication by a nonunit algebraic integer lambda with absolute norm N, the corresponding quantities are

    Q_new B_*new=NQB_*,
    E_new/B_*new=E/(NB_*),

so the rate comparison worsens. A certified division by common content may improve a previously wasteful normalization, but the resulting integral sequence still satisfies (R10); it cannot cross the universal scalar threshold.

A fixed invertible fractional-linear change over F likewise changes only fixed constants, provided its denominator does not vanish at the target. At other embeddings its invertible matrix preserves the maximum norm up to constants. At the chosen embedding the leading denominator cannot cancel identically when theta is quadratic over F and the matrix coefficients lie in F. Consequently a change of this presentation does not remove the obstruction.

#### The obstruction for transported power seeds can be seen before Padé estimates

Take a nonzero algebraic integer xi=a+b eta in the same real quadratic extension, with a,b in O and b!=0. Put

    delta=Norm_(K/F)(xi),
    Q=|xi|,
    E=1/|xi_bar|,
    B=max(|xi'|,|xi_bar'|).

When the chosen embedding supplies a shrinking error, powers of xi give scalar approximants with these rates; their cross determinants are a nonzero fixed factor times delta^j. But

    E/Q=1/|delta|,
    B^2>=|delta'|,
    |delta delta'|=|Norm_(K/Q)(xi)|>=1.

Hence E/(Q B^2)<=1. If a,b are both nonzero, the two real conjugates xi',xi_bar' have unequal absolute values, so the inequality is strict. Thus making one conjugate pair dominant by a different integral seed cannot beat the scalar norm-determinant threshold either.

### I.5. An explicit rational conjugation, and what it does not descend

The relative conjugate beta_bar=3epsilon+2eta is a rational fractional-linear function of beta:

    beta_bar=(5beta+6)/(6beta-5).                      (R13)

Indeed beta+beta_bar=6epsilon and beta beta_bar=5epsilon+1, so

    (6beta-5)beta_bar=6(5epsilon+1)-5(6epsilon-beta)=5beta+6.

For the binary form this gives the exact identity

    F_Fib(-5u+6w,6u+5w)=61^2 F_Fib(u,w).                  (R14)

The matrix squares to 61I and multiplies u^2+w^2 by 61. For a primitive F_Fib=-1 solution, its two transformed coordinates are still coprime: a common prime must divide the determinant 61, but a common factor 61 would force 61^4 to divide the transformed form value -61^2, impossible. Thus this conjugation moves the solution to right-hand side -61^2 and increases its Euclidean coordinate size by sqrt(61). Applying the map twice and removing the common factor returns to the original point.

This supplies an exact two-branch transport and explains the appearance of 61 in the conic cover. It is not a height-decreasing self-map of F_Fib=-1. A new descent through this related equation would have to impose and exploit an additional condition; the conjugation alone only cycles the presentation.

### I.6. What is left for a genuinely coupled construction

The natural pair of radical functions can be taken as sqrt(5) and eta=sqrt((5+sqrt(5))/2). Their two quadratic steps are coupled by eta eta'=sqrt(5). A construction that treats the second root over F but then bounds the other F-embedding only by size has the proved obstruction in Section I.4.

The three-dimensional Gaussian span in P07 is still smaller than a full degree-four basis. With its fourth-root parameter Z,

    sqrt(5)=2i(1+Z^2)/(1-Z^2)-1,
    eta=-2iZ/(1-Z^2),

on the compatible branch. After the common denominator 1-Z^2 is cleared, the target span is exactly that of 1,Z,Z^2. In those coordinates the change has rows

    (1,0,-1), (2i-1,0,2i+1), (0,-2i,0),

with determinant -8. It is an invertible projective change over Q(i), with only a fixed denominator cost. Thus merely renaming these radicals does not alter the approximation lattice. A successful coupled-square-root method must improve its arithmetic normalization or obtain stronger correlated remainder bounds, rather than drop the second real embedding from the determinant calculation.

The exact remaining opportunity is therefore outside the scalar norm-determinant architecture: use a common rational/Gaussian approximation lattice for two coupled errors, or use additional arithmetic information about the unknown in the norm lower bound. Nothing in the obstruction rules out either. No passing coupled separator for F_Fib is proved in this note.

## Part II. Coupled Markov–Pade constructions for every root

### II.1. Two elementary structural restrictions

PROVED. Let K=Q(rho), rho^2=10+2sqrt(5). Its Galois group is cyclic of order four. An explicit proof is useful: 10+2sqrt(5) is not a square in Q(sqrt(5)), since its norm is 80, which is not a rational square. Thus rho has degree four, with polynomial T^4-20T^2+80. The element rho'=rho^3/4-3rho equals sqrt(10-2sqrt(5)); it satisfies rho rho'=4sqrt(5). Sending rho to rho' gives an automorphism whose square sends rho to -rho, and hence has order four. No pair of independent square roots of fixed rational numbers can generate K: their compositum has the three independent sign changes and Galois group C2 x C2, whereas K has only one involution. If the square roots are dependent, their compositum has degree at most two. Thus a direct application of a simultaneous-approximation theorem for two independent rational square roots is not a representation of this field. A nested radical, a genuinely relative construction, or a larger coefficient lattice must retain its extra arithmetic cost.

This does not prohibit simultaneous square-root functions with a variable parameter or radicands in Q(sqrt(5)). It rules out the particular fixed biquadratic shortcut.

For beta=(3+4Z+3Z^2)/(i(Z^2-1)), Z^4=w, rationalization gives

    beta=-i [3(1+w)+4w^(1/4)+6w^(1/2)+4w^(3/4)]/(w-1).       (1)

Unlike separately approximating Z and Z^2, one can approximate this entire prescribed combination. Its scalar Padé denominator then couples the three fractional powers from the start.

### II.2. The exact positive moment sequence

Put x=1-w and define M(x) by

    3(1+w)+4w^(1/4)+6w^(1/2)+4w^(3/4)=20-10x-x^2 M(x).

Consequently

    beta=i(20/x-10-xM(x)).                                (2)

For |x|<1, binomial expansion gives M(x)=sum_(n>=0) m_n x^n, where

    m_n=sum_(alpha in {1/4,1/2,3/4})
          c_alpha alpha(1-alpha)(2-alpha)_n/(n+2)!,
    (c_(1/4),c_(1/2),c_(3/4))=(4,6,4).                   (3)

Every m_n is a positive rational number. In particular

    m0=3/2, m1=3/4, m2=121/256.

For a formulation requiring no gamma-function identity, let nu_alpha be the probability measure on [0,1] with density proportional to

    t^(1-alpha)(1-t)^alpha.

Integration by parts gives its n-th moment (2-alpha)_n/(3)_n. Therefore the measure

    mu=sum_alpha [c_alpha alpha(1-alpha)/2] nu_alpha

has moments (3), total mass 3/2, and a strictly positive density on (0,1). Also mu is symmetric under t -> 1-t, since the alpha=1/4 and alpha=3/4 weights are equal and the alpha=1/2 density is symmetric. We have

    M(x)=integral_0^1 dmu(t)/(1-xt),                      (4)

initially by its geometric series, then throughout the slit plane by the elementary integral identity. In particular (4) is valid at x=1-Ubar/U when U has nonzero real and imaginary parts.

The normalized alpha=1/2 density is (8/pi)sqrt(t(1-t)). Its weight in mu is 3/4, so

    dmu(t) >= (6/pi)sqrt(t(1-t)) dt.                     (5)

The other two normalized densities can also be evaluated by the substitution t=r^4/(1+r^4) and elementary partial fractions. Equivalently, the complete density is

    (2sqrt(2)/pi)[t^(3/4)(1-t)^(1/4)+t^(1/4)(1-t)^(3/4)]
      +(6/pi)sqrt(t(1-t)).                              (6)

All constants used in the estimates below need only the total mass and (5).

For an elementary check of the normalization in (6), the substitution t=v^4/(1+v^4) gives

    integral_0^1 t^(3/4)(1-t)^(1/4)dt
       =4 integral_0^infinity v^6/(1+v^4)^3 dv
       =(3/8) integral_0^infinity v^2/(1+v^4)dv
       =3pi sqrt(2)/32.

The middle equality follows by integrating the derivatives of v^3/(1+v^4)^2 and v^3/(1+v^4); their boundary terms vanish. The last integral is pi/(2sqrt(2)), obtained by factoring v^4+1 into its two real quadratics and integrating their partial fractions. Interchanging t and 1-t gives the alpha=3/4 case. The alpha=1/2 integral is pi/8 by t=(1+cos(theta))/2. These evaluations yield exactly the three weights in (6), with no special-function normalization assumed.

### II.3. An exact Padé determinant which never vanishes

Let Delta_0=1 and

    Delta_N=det[m_(r+s)]_(0<=r,s<N), N>=1.

PROVED: Delta_N>0 for every N. For a nonzero real vector a, its quadratic form is

    sum a_r a_s m_(r+s)=integral (sum a_r t^r)^2 dmu(t)>0.

Thus the Hankel matrix is positive definite, and elementary elimination gives a positive determinant.

Define the monic degree-N polynomial

    q_N(t)=(1/Delta_N) det
      [m0       m1       ... mN
       m1       m2       ... m_(N+1)
       ...
       m_(N-1) mN       ... m_(2N-1)
       1        t        ... t^N].                      (7)

It is characterized by integral t^j q_N(t)dmu(t)=0 for 0<=j<N. All its coefficients are rational. Put

    Q_N(x)=x^N q_N(1/x), Q_0=1,
    P_N(x)=the terms of degrees 0,...,N-1 in Q_N(x)M(x),
    P_0=0,
    h_N=integral q_N(t)^2 dmu(t)=Delta_(N+1)/Delta_N>0.

Orthogonality gives

    Q_N M-P_N=O(x^(2N)).

The exact consecutive determinant is

    P_N Q_(N-1)-P_(N-1)Q_N=h_(N-1)x^(2N-2), N>=1.       (8)

Proof. Both sides of the determinant have degree at most 2N-2. Substituting the two remainder expansions shows vanishing through degree 2N-3. The leading coefficient is h_(N-1), since the first nonzero coefficient of Q_(N-1)M-P_(N-1) is integral t^(N-1)q_(N-1)(t)dmu=h_(N-1). This proves (8) as a polynomial identity, not merely at a selected point.

For the beta rational functions set

    B_N(x)=i[(20-10x)Q_N(x)-x^2P_N(x)],
    C_N(x)=xQ_N(x).

Then

    B_N C_(N-1)-B_(N-1)C_N
      =-i h_(N-1)x^(2N+1).                             (9)

This determinant is nonzero at every nonzero x. The positivity proof supplies all-index normality automatically.

### II.4. Elementary analytic bounds with sharp exponential bases

Assume U=A+iB with integers A>0, B!=0. Write

    R=sqrt(A^2+B^2), delta=U-Ubar=2iB,
    x=delta/U,
    Lambda_+=(R+A)/2, Lambda_-=(R-A)/2,
    r=(R+A)/|B|>1.

In particular Lambda_+ Lambda_-=B^2/4 and Lambda_-/Lambda_+=r^(-2).

Every zero of q_N is simple and lies in (0,1). To prove this elementary fact, multiply q_N by the polynomial whose roots are exactly its sign-changing zeros in (0,1). If there were fewer than N such zeros, the product would have fixed sign on the interval and nonzero integral, contradicting orthogonality. This also proves that Q_N(x) is nonzero at our nonreal x.

Use shifted Chebyshev polynomials U_j(2t-1). They have leading coefficient 4^j and

    integral_0^1 U_j(2t-1)U_k(2t-1)sqrt(t(1-t))dt
      =0 if j!=k, and pi/8 if j=k.

These identities follow from t=(1+cos theta)/2 and the sine orthogonality formula. The monic degree-N Chebyshev T polynomial has supremum at most 2*4^(-N), so the minimizing property of the monic orthogonal polynomial gives

    h_N<=6*16^(-N).

Expand q_N=sum_(j=0)^N a_j U_j(2t-1). By (5),

    sum_j |a_j|^2<=8*16^(-N).

Let s=1/x and choose zeta with 2s-1=(zeta+zeta^(-1))/2 and |zeta|=r. Here zeta is purely imaginary, and direct substitution gives this stated modulus. Since

    U_j((zeta+zeta^(-1))/2)
      =(zeta^(j+1)-zeta^(-j-1))/(zeta-zeta^(-1)),

summing the geometric bound yields

    |delta^N q_N(U/delta)|<=C_q Lambda_+^N,
    C_q=4sqrt(2) r^2/[(r-r^(-1))(r-1)].                (10)

Every constant is explicit, and the estimate holds for every N>=1.

For completeness the Padé error can be bounded without asymptotic orthogonal-polynomial theory. Gaussian quadrature at the N zeros of q_N has positive weights of total mass 3/2 and is exact on polynomials of degree <=2N-1. Both claims follow by polynomial division and orthogonality: the weight for a Lagrange polynomial equals the integral of its square. Its value on (1-xt)^(-1) is P_N/Q_N.

The elementary Chebyshev expansion is

    1/(1-xt)=4/[x(zeta-zeta^(-1))]
       [1+2 sum_(j>=1) zeta^(-j)T_j(2t-1)].

Truncating after degree 2N-1 and applying the positive quadrature gives

    |M(x)-P_N(x)/Q_N(x)|<=C_m r^(-2N),
    C_m=24/[|x|(r-r^(-1))(1-r^(-1))].                (11)

This is the analytic gain available to this new coupled construction.

### II.5. The exact arithmetic multiplier and resulting exponent

Let k_N be the least positive integer clearing all coefficients of P_N and Q_N. Homogenize the beta approximant:

    d_N=k_N delta U^N Q_N(delta/U),
    b_N=i k_N [(20U-10delta)U^NQ_N(delta/U)
                  -delta^2U^(N-1)P_N(delta/U)].         (12)

Both are Gaussian integers. Divide them by any common Gaussian integer eta_N; choosing a Gaussian gcd makes the pair primitive. Put

    a_N=k_N/|eta_N|.

The exact determinant after division is the nonzero Gaussian integer

    (b_N/eta_N)(d_(N-1)/eta_(N-1))
       -(b_(N-1)/eta_(N-1))(d_N/eta_N)
    =-i k_N k_(N-1) h_(N-1) delta^(2N+1)
                  /(eta_N eta_(N-1)).                  (13)

The all-index analytic bounds give

    |d_N/eta_N| <= |delta| C_q a_N Lambda_+^N,
    |beta d_N/eta_N-b_N/eta_N|
      <= (|delta|^2/R) C_q C_m a_N Lambda_-^N.          (14)

Consequently the missing arithmetic lemma has a very exact form. If constants C>0 and gamma>0 are proved such that

    a_N<=C gamma^N for every N>=1,

and gamma Lambda_-<1, then (13)-(14) give a standard nonzero-determinant separator with

    Q=gamma Lambda_+,
    E=1/(gamma Lambda_-),
    mu=1+log(Q)/log(E).

To obtain mu<4 one needs

    gamma^4 Lambda_+ Lambda_-^3<1.                     (15)

The finite constants are those in (14), multiplied by C; the ordinary consecutive-determinant lemma supplies the explicit lower-bound constant, retaining the small prefactor as usual.

For the original Fibonacci target one may take U=1+2i, because multiplying 2+4i by a rational real factor does not change Ubar/U. Then

    Lambda_+=(1+sqrt(5))/2=epsilon,
    Lambda_-=epsilon^(-1),
    1<=gamma<sqrt(epsilon)                             (16)

is the possible useful interval. The lower bound gamma>=1 follows from the nonzero scalar integer determinants: E<=Q at the exponential-rate level. Condition (16) is not proved for the actual arithmetic multipliers. Direct exact computations of k_N and gcds show very substantial growth, not evidence for (16).

The positive measure also implies symmetry q_N(1-t)=(-1)^Nq_N(t). This proves that U^NQ_N(delta/U) is real: conjugation changes delta to -delta, and -Ubar/delta=1-U/delta. Symmetric Gaussian quadrature similarly gives, for R_N=P_N/Q_N,

    R_N(x/(x-1))=(1-x)R_N(x).

Here xbar=x/(x-1). Substituting this identity in i(20/x-10-xR_N(x)) shows that this beta approximant is real. Therefore both b_N and d_N in (12) are purely imaginary Gaussian integers. Removing i and their ordinary integer gcd produces rational approximants; the Gaussian primitive choice differs from this by a Gaussian unit, so no extra exponential cost is involved. No hidden cost from another real coefficient-field embedding occurs; the unresolved cost is the explicitly defined a_N.

### II.6. Why a closed Jacobi product cannot simply be borrowed

PROVED obstruction to a specified shortcut. The density (6) is not a rational multiple of a single Jacobi density t^a(1-t)^b, for any real a,b. Near t=0 it has nonzero terms with exponents 1/4,1/2,3/4. A rational multiple of t^a(1-t)^b has, after factoring its leading power, a convergent expansion in integer powers of t only. The three distinct fractional parts give a contradiction.

Thus ordinary finite Christoffel/Geronimus modifications of one Jacobi weight do not turn the Hankel determinants here into the standard closed Jacobi product.

The quartic substitution t=v^4/(1+v^4) makes the measure rational:

    dmu = (8sqrt(2)/pi)
       v^4(v+sqrt(2))(v+1/sqrt(2))/(1+v^4)^3 dv.

But q_N(t) then becomes a rational function with denominator (1+v^4)^N and lacunary numerator of degree 4N. The ordinary degree-N polynomial space is not preserved. The rationalization therefore does not justify applying a usual Jacobi Hankel formula. It could still be the starting point of a new multiple-orthogonality or arithmetic cancellation theorem.

### II.8. Optional exact positive repair of the signed target branch

This is a second way to handle beta_* directly and a reusable finite-sign-change identity. It is not needed for the rational involution above.

Replace (4,6,4) by (-4,6,-4) in (3), and call the resulting moments m_n^-. Their first values satisfy m_0^-=m_1^-=0, m_2^-=-1/256. The signed density is

    rho_-(t)=[6s-2sqrt(2)*sqrt(s(1+2s))]/pi,

Its sign changes exactly at t=1/5 and 4/5. Set

    q_2(t)=t^2-t+4/25,
    nu(t)=100s/[pi (6s+2sqrt(2)*sqrt(s(1+2s)))(5s+2)].

Rationalizing the density proves rho_-=-q_2 nu, with nu>0 on (0,1). The vanishing moments m_0^-=m_1^-=0 prove that q_2 is the monic degree-two orthogonal polynomial for the positive measure nu(t)dt.

    M_-(x)=-x^2 M_tilde(x)/(1-x+4x^2/25).

One can verify this directly at the moment level:

    tilde_m_n=-m_(n+2)^-+m_(n+1)^--(4/25)m_n^-.

Consequently the requested branch has the direct positive-Markov representation

    beta_*=i[4/x-2+x^3 M_tilde(x)/(1-x+4x^2/25)].

Every Hankel determinant of tilde_m_n is strictly positive by the same Gram proof as before. Its Padé cross determinant is therefore nonzero at all indices. No unproved normality of a signed Hankel matrix is necessary. Its separate arithmetic multipliers still need analysis; positivity and a fixed rational prefactor do not supply the missing exponential denominator estimate.

More explicitly, let P_N,Q_N now denote the Padé numerator and denominator for M_tilde, and let h_N be its positive monic norm. Put r(x)=1-x+4x^2/25 and

    C_N^-(x)=x r(x) Q_N(x),
    B_N^-(x)=i[(4-2x)r(x)Q_N(x)+x^4P_N(x)].

Then the exact target-branch determinant is

    B_N^- C_(N-1)^- - B_(N-1)^- C_N^-
       =i h_(N-1) x^(2N+3) r(x).

This follows immediately from (8) for the repaired moments: the polynomial part cancels, and the remainder is i x^5 r(x)(P_N Q_(N-1)-P_(N-1)Q_N). At our nonreal x, neither x nor r(x) is zero. The two zeros of r are 5 and 5/4, both on the excluded real cut.

FINITE-SIGN-CHANGE REPAIR LEMMA (PROVED). Let nu be a finite positive measure on [0,1] with infinitely many points in its support. Let q_d be monic of degree d, and let rho=q_d nu. Suppose integral t^j drho(t)=0 for 0<=j<d. Then q_d is the monic orthogonal polynomial of degree d for nu, and, with q_d^*(x)=x^d q_d(1/x),

    M_rho(x)=x^d M_(q_d^2 nu)(x)/q_d^*(x).

Proof. For s outside [0,1], the polynomial [q_d(s)-q_d(t)]/(s-t) has degree at most d-1 in t. Its integral against q_d(t)dnu(t) vanishes. Thus

    q_d(s) integral q_d(t)/(s-t)dnu(t)
       = integral q_d(t)^2/(s-t)dnu(t).

Set s=1/x, and multiply by the needed powers of x. All zeros of q_d lie in (0,1), by the sign-change argument in Section II.4, so the division is legitimate off the integration cut. The measure q_d^2 nu is positive and has infinitely many support points. Hence all its Hankel determinants are positive. A density -q_d nu gives the same identity with a minus sign, as in our example. This proves the lemma without an asymptotic or arithmetic assumption.

For the explicit repaired measure, the analytic exponential bases remain Lambda_+,Lambda_-. Indeed, writing s=sqrt(t(1-t)) in its density, 0<s<=1/2 gives

    nu(t) >= [100/(27pi)]sqrt(t(1-t)).

The total mass of mu_tilde is 1/256. If q_N is its monic orthogonal polynomial, the monic Chebyshev comparison gives integral q_N^2 dmu_tilde <=(1/64)16^(-N). The displayed density lower bound controls the Chebyshev coefficients of the polynomial q_2 q_N, of degree N+2. Evaluating this polynomial outside [0,1] and dividing by q_2(1/x), which is nonzero there, changes only the fixed factor and the fixed-degree r^2 factor in Section II.4. Positive Gaussian quadrature supplies the same r^(-2N) error base. Thus fixed sign-change repair does not lose an exponential analytic rate; it changes the arithmetic sequence and fixed constants.

Arbitrary signed densities do not automatically satisfy the required moment vanishing. Nor does this lemma give an exponential bound for the coefficient denominators or primitive specialized pairs; that remains the precise arithmetic gap.

### II.9. Completing the analytic construction at the other two roots

#### II.9.1. Coercivity gives all-index normality

Put v(t)=sqrt(t(1-t)). The density is

    w_sigma(t)=-(6/pi)v(t)
       +sigma (2sqrt(2)i/pi)
          [t^(3/4)(1-t)^(1/4)-t^(1/4)(1-t)^(3/4)].

It satisfies

    Re w_sigma(t)=-c v(t), c=6/pi,
    w_sigma(1-t)=overline(w_sigma(t)).

For any nonzero complex vector a,

    Re(sum_(j,k) conjugate(a_j) m_(j+k) a_k)
       =-c integral_0^1 |sum_j a_j t^j|^2 v(t)dt <0.

Thus every Hankel matrix has negative definite Hermitian part and is invertible. This proves existence of the monic q_N and nonzero Hankel determinants at ALL indices, even though the weight is complex. Orthogonality against monomials implies orthogonality against every polynomial of degree less than N, including polynomials with conjugated coefficients.

Define Q_N, P_N, h_N as before, now over Q(i). The same algebra proves

    P_N Q_(N-1)-P_(N-1)Q_N=h_(N-1)x^(2N-2),
    h_N=Delta_(N+1)/Delta_N !=0.

Indeed h_N=integral q_N(t)^2 w_sigma(t)dt also equals integral |q_N(t)|^2 w_sigma(t)dt: the difference pairs q_N with the polynomial q_N-conjugate(q_N), whose degree is less than N. Hence Re h_N<0. The reflection symmetry below additionally makes h_N real, so h_N<0.

#### II.9.2. Explicit growth bound without locating the zeros

The squared weighted size of the density has an elementary exact integral:

    A2=integral_0^1 |w_sigma(t)|^2/v(t)dt
       =(8+5pi/2)/pi^2.                                (18)

To check it, the square of the bracket in the imaginary part is v(1-2v), so |w_sigma|^2/v=(8+20v)/pi^2; use integral v=pi/8.

Let p_N be the monic Chebyshev polynomial, whose supremum on [0,1] is at most 2*4^(-N). Orthogonality to conjugate(q_N-p_N) gives

    c ||q_N||_v^2
       <= |integral q_N conjugate(p_N) w_sigma|
       <= ||q_N||_v * 2*4^(-N)*sqrt(A2).

Therefore, for every N>=1,

    ||q_N||_v <= K0*4^(-N),
    K0=2sqrt(A2)/c=sqrt(8+5pi/2)/3.

Expanding q_N in the shifted Chebyshev U basis gives the coefficient bound

    sum_j |a_j|^2 <= (8/pi)K0^2 *16^(-N).

Exactly the geometric summation in Section II.4 then proves

    |U^N Q_N(delta/U)| <= Cq Lambda_+^N,
    Cq=2K0 sqrt(8/pi) r^2/[(r-r^(-1))(r-1)].           (19)

No assertion that all zeros of q_N lie on [0,1] is used or needed.

#### II.9.3. Direct residual estimate replaces Gaussian quadrature

The exact residual identity is

    Q_N(x)M_sigma(x)-P_N(x)
       =x^N integral_0^1 q_N(t)w_sigma(t)/(1-xt)dt.     (20)

It follows by polynomial division and orthogonality. Subtract from the kernel its Chebyshev expansion through degree N-1. The subtracted polynomial integrates to zero against q_N w_sigma. The remaining kernel has supremum at most

    Ct r^(-N),
    Ct=8/[|x|(r-r^(-1))(1-r^(-1))].

Cauchy--Schwarz, (18), and the q_N norm bound consequently give

    |U^N(Q_NM_sigma-P_N)|
       <= K0 sqrt(A2) Ct Lambda_-^N.                  (21)

This direct estimate is stronger for the present purpose than controlling the rational error M_sigma-P_N/Q_N: it avoids dividing by Q_N at the specialization.

#### II.9.4. Rational specialization and exact determinant

Let k_N be the least positive integer clearing both real and imaginary coefficient denominators in P_N,Q_N. Define

    d_N=k_N U^N Q_N(delta/U),
    b_N=-2 sigma d_N-i k_N delta U^(N-1)P_N(delta/U),   (22)

with the second term zero at N=0. These are actually rational integers, not merely Gaussian integers.

Here is a proof which does not divide by a specialized Q_N. Reflection and uniqueness imply

    conjugate(q_N)(1-t)=(-1)^N q_N(t).

For the second-kind polynomial

    r_N(s)=integral [q_N(s)-q_N(t)]/(s-t) w_sigma(t)dt,

we have

    r_N(1-s)=(-1)^(N+1) conjugate(r_N)(s),
    U^(N-1)P_N(delta/U)=delta^(N-1)r_N(U/delta).

Since conjugate(U/delta)=1-U/delta and conjugate(delta)=-delta, both U^NQ_N and U^(N-1)P_N are real. The expression -i delta is real too. Formula (22), already Gaussian integral by denominator clearing, is therefore rational integral.

Its consecutive determinant is exactly

    b_N d_(N-1)-b_(N-1)d_N
       =-i k_N k_(N-1) h_(N-1) delta^(2N-1) !=0.      (23)

Let eta_N=gcd(|b_N|,|d_N|), and put a_N=k_N/eta_N. The primitive pair obeys

    |d_N/eta_N| <= Cq a_N Lambda_+^N,
    |beta_sigma d_N/eta_N-b_N/eta_N|
       <= Ce a_N Lambda_-^N,
    Ce=16A2/[c(r-r^(-1))(1-r^(-1))].                  (24)

The normalized determinant is the right side of (23) divided by eta_N eta_(N-1), and remains a nonzero integer.

A specialized denominator d_N has not been proved nonzero at every index. That causes no difficulty: (23) excludes a zero numerator-denominator pair. If the needed arithmetic bound a_N<=C gamma^N with gamma Lambda_-<1 is proved, (24) eventually makes the primitive linear error less than 1. A zero denominator would then require a nonzero integer numerator of absolute value less than 1, impossible. Thus all sufficiently large denominators would be nonzero, with an explicit threshold.

## Part III. Cubic presentation invariance and its exact logical limits

### III.1. A necessary correction to the stated all-seed premise

PROVED: presentation invariance identifies the score of a seed in one cubic presentation with the score of its corresponding rational projective seed in another presentation. It does not make the score constant as the seed varies. Therefore a finite continued-fraction search, however large, together with presentation invariance is not an all-seed failure certificate.

This distinction is substantive for the 165 fibres. The calculations reported in the question certify failure for the searched seeds and quantify how exceptional a later passing seed would have to be. Unless a separate universal inequality for all rational seeds has been proved, the assertion that every seed fails remains UNPROVED. The next proposition makes the difference particularly sharp: an actual all-seed failure theorem would already give a tiny bound for every norm-one solution in all these fibres.

### III.2. PROVED: all-seed failure would itself finish the Thomas norm-one equations

For an integer a>=1 write

    F_a(x,y)=x^3-(a-1)x^2y-(a+2)xy^2-y^3,
    d=a^2+a+7,
    K=x^2+xy+y^2,
    L=-(2a+1)x^3-3(a+5)x^2y+3(a-4)xy^2+(2a+1)y^3.

The exact cubic covariants of P06 are

    Delta=d^2, H=dK, J=dL,
    L^2+27F_a(x,y)^2=4dK^3.                            (S1)

The companion certificate verifies these identities as polynomials. In particular, for a solution F_a(x,y)=f with f=+/-1, x,y are primitive and K is odd. Since d is odd, (S1) gives L odd.

In the Eisenstein integer basis 1,omega, with omega^2+omega+1=0, the unnormalized Kummer coefficient divided by the fixed factor d is

    (L+3f sqrt(-3))/2=(L+3f)/2+3f omega.

Its content g0 is either 1 or 3. After dividing by g0, P06's exact data are

    D0=27/g0^2,
    lambda=(|L|+sqrt(L^2+27))/g0,
    gamma=1 if g0=1, and gamma=3 if g0=3.

Consequently

    g0 gamma^3 D0^2=729,
    score(x,y)=(|L|+sqrt(L^2+27))/729.                   (S2)

The possible content cancellation cancels exactly from this norm-one score. Squaring the positive comparison, or using P06's elementary integer test, shows

    score(x,y)>1 iff |L|>=365.                          (S3)

Here L is odd; equality score=1 cannot occur. Thus if a separate theorem established score<=1 for every primitive seed of this fibre, every F_a=+/-1 solution would satisfy |L|<=363 and hence

    K^3 <= (363^2+27)/(4d)=32949/d.

Since d>=9,

    K<=15,
    (3/4)x^2<=K, (3/4)y^2<=K,
    |x|<=4, |y|<=4.                                   (S4)

The last box is independent of a. Evaluating its 81 pairs, with the parameter a restricted to the finitely many fibres, would then finish the entire claimed all-failure collection.

The certificate performs this conditional endpoint for the precise 165-element set reported in the question. In that box a=1 has the six extra signed pairs listed below; every other member of the set has only the six signed trivial pairs (1,0),(0,-1),(-1,1) and their negatives. This is a conditional consequence, not a proof that all seeds fail. It explains why substituting presentation invariance for the missing universal quantifier would silently solve the original hard problem. ### III.3. PROVED: there is no independent non-cube Kummer twist preserving this cubic field

Let K/Q be a cyclic cubic field and let k=Q(omega). Suppose L=Kk has a presentation

    L=k(z), z^3=c in k, c not a cube in k.

Let sigma generate Gal(L/k), normalized by sigma(z)=omega z. If z' in L satisfies (z')^3 in k and k(z')=L, then

    z'=a z or z'=a z^2, for some a in k^*.

Proof. Because (sigma(z')/z')^3=1, sigma(z')/z' is 1, omega, or omega^2. It cannot be 1, since z' generates L. Expand z'=a0+a1 z+a2 z^2 in the k-basis 1,z,z^2 and compare coefficients under sigma. In the omega eigenspace only a1 can be nonzero; in the omega^2 eigenspace only a2 can be nonzero. This proves the claim.

Thus the only generating radicand classes for the same extension are

    c'=a^3 c or c'=a^3 c^2.                             (S5)

A genuinely different non-cube twist changes the extension. It does not give a new binomial description of the same cubic field.

For the unit-circle presentation relevant to totally real cyclic cubics, choose z bar(z)=1 and likewise z' bar(z')=1. Then the multiplier a above has a bar(a)=1. Every such a in k is explicitly of the form

    a=t/bar(t), t in k^*.

For a!=-1 take t=1+a, because bar(a)=1/a; for a=-1 take t=sqrt(-3). Write t in the rational basis 1,omega and clear denominators. This is precisely a rational projective seed of the existing construction. Replacing z by z^2 is the inverse cube-root branch, up to a cube in k, and does not create a new normalized quality score.

This proves an obstruction for the proposed natural class: changing the cyclic Kummer presentation, including a Gaussian-period expression that merely supplies another generator of the same field, cannot evade the seed score after the arithmetic lattice is transported correctly. It does not rule out a different approximation construction for that same algebraic function.

### III.4. PROVED: every cubic generator change is already fractional linear

Let theta and eta be nonrational elements of the same degree-three field K. The four elements 1,theta,eta,theta eta are linearly dependent over Q. Thus

    a+b theta+c eta+d theta eta=0

for some rational a,b,c,d, not all zero. The coefficient c+d theta is nonzero, for otherwise c=d=0 and then a=b=0. Hence

    eta=-(a+b theta)/(c+d theta).

The fractional-linear determinant is nonzero; a zero determinant would make eta rational. Therefore all nonrational cubic generators are related by an invertible rational fractional-linear map.

Combining this with (S5) and P06's proved covariance explains exactly why a new resolvent root or a re-labelled Gaussian period is not, by itself, a new separator. The analytic approximation identity, the integral lattice, or a globally necessary covering condition must change.

An elementary example of the right-hand-side cost is

    F_1(-x+y,2x+y)=3F_4(x,y).                           (S6)

The matrix has determinant -3. Thus the isomorphism between these two cubic presentations sends F_4=+/-1 to F_1=+/-3, not to F_1=+/-1. A classification of the latter norm-one equation alone cannot be pulled back to solve a=4. Such norm multipliers must be kept in any descent through a related family member.

### III.5. What an auxiliary cover would still need

PROVED implication. A finite collection of auxiliary-polynomial or congruence certificates on bounded exponent boxes only covers the boxes certified. Unit coverage does not turn that collection into a cover of the unbounded integer exponent lattice. A complete proof requires an independent cutoff, a decreasing map that reaches the covered boxes, or an exact certificate covering every unbounded end.

This is an obstruction to an inference, rather than a claim that no auxiliary certificate can exist. In the two-unit cubic setting a smooth one-marker p-adic zero germ has positive dimension, so simply refining a single local chart cannot supply the missing global cutoff. The successful route for a=1 changes the necessary covering equation and the signature/unit-marker balance; it does not extract a cutoff from unsuccessful seed searches.

### IV.2. Elementary principalization in Z[cuberoot(6)]

Let mu be the real cube root of 6, and put R=Z[mu]. Irreducibility follows from Eisenstein at2. Its norm is

    N(a+b mu+c mu^2)=a^3+6b^3+36c^3-18abc.

We need a Bezout property in this particular ring. We prove it through integer lattices; no class group, class number, or ideal-factorization theorem is invoked.

#### IV.2.1 A small-index representative for every stable lattice

A full-rank integer lattice I contained in R is called stable if mu I is contained in I. Write h=[R:I]. In the real/complex embedding

    a -> (a^(1), Re(a^(2)), Im(a^(2))),

the covolume of I is 9 sqrt(3) h. This follows directly from the determinant of the embedding matrix of 1,mu,mu^2; its discriminant is -972.

Consider the centrally symmetric convex body

    C_T = {(r,z) in R x C : |r| + 2|z| <= T}.

Its volume is pi T^3/6. The elementary convex-body lattice lemma says that volume greater than eight times the covolume forces a nonzero lattice point. Its proof is the usual volume pigeonhole argument: half the body has volume greater than a fundamental parallelepiped, so two of its points are congruent modulo the lattice; their difference lies in the body.

Take T^3=256h. Since pi>3 and sqrt(3)<16/9,

    pi T^3/6 = (128pi/3)h > 128h > 72sqrt(3)h.

Thus there is a nonzero beta in I with

    |N(beta)| = |beta^(1)| |beta^(2)|^2
              <= (T/3)^3 = (256/27)h < 10h.

The inequality is the arithmetic-geometric mean inequality applied to |beta^(1)|,|beta^(2)|,|beta^(2)|.

Because beta R is contained in I, the integer

    q = [I:beta R] = |N(beta)|/h

is at most9. Set L=beta^(-1) I. Then R is contained in L and [L:R]=q<=9.

For p=2 or3, multiplication by mu is nilpotent on the p-torsion, because mu^3=6=0 there; hence its kernel contains a nonzero vector and thus an invariant line. For p=5 or7, the p-primary part has order p, since p^2>9. This proves the assertion in all cases.

Consequently there is an intermediate stable lattice L1=pi^(-1)R with [L1:R]=p. Multiplying L by pi reduces its index over R to q/p. Induction on q shows that L is principal. Therefore I=beta L is principal.

Applied to the stable lattice generated by two nonzero elements of R, this proves their Bezout property. Factorization into irreducibles terminates by strict decrease of the absolute norm. Bezout proves Euclid's lemma, so element factorization is unique up to units. This is all the factorization theory required below.

#### IV.2.3 Complete elementary unit coverage in R

Put

    e=1-6mu+3mu^2.

Its norm is1 and 0<e<1. Every positive unit z in R can be multiplied by a power of e so that

    sqrt(e) <= z^(1) < 1/sqrt(e).

There is no unit theorem in this assertion: choose the integer power by the Archimedean ordering of powers of the single known positive real number e. Since N(z)=1, the complex conjugate has absolute value (z^(1))^(-1/2).

The certificate checks, by rational intervals for mu,

    e^(-1/2)<18.1,    e^(-1/4)<4.26.

Fourier inversion using the conjugates mu,mu*zeta,mu*zeta^2 gives, for z=a+bmu+cmu^2,

    |a| <= (18.1+2*4.26)/3 <9,
    |b| <= (18.1+2*4.26)/(3mu) <5,
    |c| <= (18.1+2*4.26)/(3mu^2) <3.

The finite norm enumeration in |a|<=8,|b|<=4,|c|<=2 gives only ±1. A normalized positive unit must therefore be1. Thus

    R^× = { ± e^j : j in Z }.

This is proved directly for this ring, with no assertion about a general unit group.

### IV.3. The square covering of X^2+3=4Y^3

For an integer solution, Y>=1, X and Y are odd, and 3 divides neither X nor Y. The last assertion follows by comparing 3-adic valuations if 3 divides X; the parity assertions follow modulo4 and8.

Set

    alpha=2Y-mu,
    beta=4Y^2+2Ymu+mu^2,
    pi=2-mu.

Then

    alpha beta = 2X^2,
    N(alpha)=2X^2,
    pi^3=2e,    N(pi)=2.

The only possible common irreducible divisor of alpha and beta is pi. Indeed a common irreducible divides 12Y^2 after putting mu=2Y modulo alpha. If it divides Y, it also divides mu and hence6, which is excluded by gcd(Y,6)=1. The prime above3 cannot divide alpha because 3 does not divide N(alpha). Above2 there is only pi, since pi^3=2e.

Moreover the exponent of pi in alpha is exactly1. Indeed

    alpha=pi+2(Y-1)=pi[1+pi^2 e^(-1)(Y-1)],

and the bracket is1 modulo pi. All other irreducibles appearing in alpha have even exponents. Unique element factorization and the complete unit coverage therefore give

    2Y-mu = (2-mu)e^i (u+vmu+wmu^2)^2,    i=0 or1,

with u,v,w integers. Here a sign is unnecessary: alpha and 2-mu are positive at the real embedding, so the unit factor is positive. Its even power of e has been absorbed into the square.

The common divisor of u,v,w is1, since its square would divide the coefficient -1 of mu on the left.

#### IV.3.1 The i=1 cover is finite immediately

Comparing the mu^2 and mu coefficients gives

    6u^2-8v^2-39w^2-13uv-16uw+72vw=0,
    13u^2-72v^2+96w^2+32uv-144uw+156vw=1.

Put

    L=-u+4v-4w,
    M=-2u+2v+3w,
    N=-2u-3v+12w.

Their coefficient determinant is -1 and the first equation is LN+M^2=0. Consequently gcd(L,M,N)=1. Up to replacing u,v,w by their negatives, the elementary parametrization of this primitive conic is

    L=m^2, M=mn, N=-n^2.

The degenerate cases L=0 or N=0 are included. Inverting the three linear equations gives

    u=20n^2+36nm-33m^2,
    v=11n^2+20nm-18m^2,
    w=6n^2+11nm-10m^2.

The second equation now becomes

    -4n^3m-3m^4=1.

Therefore m=±1 and n=∓1. This gives (u,v,w)=(-49,-27,-15), up to a simultaneous sign. Direct multiplication gives

    (2-mu)e(-49-27mu-15mu^2)^2 = 14-mu.

Thus Y=7 and X=±37.

#### IV.3.2 The i=0 cover is a quartic unit equation

The coefficient equations are

    v^2-3w^2-uv+2uw=0,
    u^2-12w^2-4uv+12vw=1.

The second equation implies u is odd and gcd(u,w)=1. Put d=2v-u. The first equation gives

    d^2=(u-2w)(u-6w).

The two factors are odd and coprime. Up to a simultaneous sign change of u,v,w, they are positive squares. Write

    u-2w=r^2, u-6w=s^2, d=rs,

with r,s odd, changing signs as necessary. Put r=m+n, s=m-n. Then

    u=m^2+4mn+n^2,
    w=mn,
    v=m^2+2mn.

If the opposite sign of d is used, exchange m,n; this gives the same covering. Substitution into the second equation yields

    n^4-6n^2m^2-4nm^3-3m^4=1.                    (Q)

It remains to prove that (Q) has only (n,m)=(±1,0).

### IV.4. Complete quartic unit coverage without a unit theorem

Let theta be a root of

    f(T)=T^4-6T^2-4T-3.

This polynomial is irreducible: it has no integer root, and a monic quadratic factorization (T^2+aT+b)(T^2-aT+d) would require bd=-3, a(d-b)=-4, b+d-a^2=-6. The four possibilities for (b,d) give b+d-a^2 equal to -3 or1, never -6.

Use the order

    O=Z[1,theta,(theta+theta^3)/2,(1+theta^2)/2].

The certificate checks that the product of any two displayed basis elements is an integer combination of them. Hence O is a ring. Equivalently its elements are

    (a+btheta+ctheta^2+dtheta^3)/2,
    a≡c mod2, b≡d mod2.

Define

    eps1=(theta^2-5)/2,
    eps2=(theta^2+2theta+1)/2.

Their norms are -1 and1, so they are units of O.

The real roots r,s and the upper complex root z have rational enclosures

    2.79549<r<2.79550,
    -2.19072<s<-2.19071,
    Re(z)=-(r+s)/2,
    Im(z)^2=-3/(rs)-Re(z)^2>0.

The signs at the endpoints prove the two real roots exist; the positive last expression shows the other two roots are nonreal. The following comparisons show that the two real logarithmic vectors of eps1,eps2 are independent:

    1<eps1(r)<3/2<eps2(r),
    0<|eps1(s)|<.101<.7<eps2(s)<1.

Indeed if a=log eps1(r), b=log eps2(r), c=-log|eps1(s)|, d=-log eps2(s), then 0<a<b and 0<d<c, hence bc-ad>0.

For any unit u of O, multiply by integer powers of eps1,eps2 until its real logarithmic vector is a linear combination of the two vectors with coefficients in [-1/2,1/2]. This uses only the existence of a real linear inverse matrix and rounding its two coordinates. The normalized unit satisfies

    |u(r)|<16/5,
    |u(s)|<19/5,
    |u(z)|<5/2.

The first two inequalities come from the endpoint bounds on eps1,eps2. The complex bound follows from the two norms and is certified by

    (eps2(r)eps2(s))/(eps1(r)|eps1(s)|) < (5/2)^4.

Lagrange interpolation at the four roots gives a finite coefficient box. Explicitly the four coefficients of f(T)/((T-r_i)f'(r_i)), in ascending order, are

    (r_i^3-6r_i-4)/f'(r_i),
    (r_i^2-6)/f'(r_i),
    r_i/f'(r_i),
    1/f'(r_i).

Using the three displayed embedding bounds and their conjugates gives, for the integer doubled coefficients of a normalized unit,

    |a|<7, |b|<9, |c|<3, |d|<2.

All inequalities are certified using rational interval arithmetic; no floating point decision is made.

The finite enumeration with |a|<=6,|b|<=8,|c|<=2,|d|<=1 and the two parity restrictions contains exactly fourteen units. They are precisely the signs of

    1, eps1, eps1^(-1), eps2, eps2^(-1), eps1 eps2, eps1^(-1)eps2.

The norm test is an integer 4x4 determinant equal to ±16 before dividing the four coefficients by2. Every unit in the normalized box therefore lies in the known two-unit subgroup. Undoing the normalization proves

    O^×={ ±eps1^p eps2^q : p,q in Z }.

No rank theorem or unit theorem is used.

### IV.5. The complete recurrence-style 2-adic isolation

Equation (Q) says that n-mtheta is a norm-one unit. Hence

    n-mtheta=±eps1^p eps2^q.

The following identities hold in Z[theta]:

    eps1^2=7+theta-theta^2,
    eps2^2=1+2theta+3theta^2+theta^3,
    eps1 eps2=(-1-3theta+theta^2+theta^3)/2.

The squares and their inverses lie in Z[theta], whereas eps1,eps2,eps1 eps2 do not. Therefore p and q are even.

Put

    eta1=(-1+theta-3theta^2+theta^3)/2=eps1^(-1)eps2^(-1),
    eta2=(1+theta+theta^2-theta^3)/2=-eps1^(-1)eps2.

Then

    eps1^2=-eta1^(-1)eta2^(-1),
    eps2^2=-eta1^(-1)eta2.

It follows that

    n-mtheta=±eta1^a eta2^b,   a≡b mod2.

The markers are the coefficients of theta^2 and theta^3.

First,

    eta1^2=13+12theta+22theta^2-10theta^3,
    eta2^2=4+4theta+7theta^2-2theta^3,
    eta1 eta2=-7-6theta-11theta^2+5theta^3.

The elements eta1^2 and eta2^2 and their inverses lie in Z[theta], as follows from their expressions in the even powers of eps1,eps2. Moreover theta^4=1 modulo2. Thus reductions of arbitrary integer powers, including negative powers, are legitimate.

If a,b are odd, reduction modulo2 gives either

    1+theta^2+theta^3  or  1+theta+theta^2.

In either case the theta^2 marker is1, impossible. Thus a,b are even.

Write a=2A,b=2B. Modulo4, eta1^2 has order dividing2 and eta2^2 has order dividing4. The marker pairs for A=0,1 and B=0,1,2,3 are respectively

    A=0: (0,0), (3,2), (2,0), (1,2),
    A=1: (2,2), (3,2), (0,2), (1,2).

Only A=0 mod2 and B=0 mod4 survives. Consequently

    a=4U, b=8V.

Here are exact return elements:

    R1=eta1^4=2701+2368theta+4320theta^2-1972theta^3,
    R2=eta2^8=438277+392560theta+711316theta^2-303200theta^3.

They have the form Ri=1+4Ki, with

    K1=675+592theta+1080theta^2-493theta^3,
    K2=109569+98140theta+177829theta^2-75800theta^3.

The two-marker drift matrix modulo2 is

    [ coeff_theta^2(K1)  coeff_theta^2(K2) ] = [0 1],
    [ coeff_theta^3(K1)  coeff_theta^3(K2) ]   [1 0].

PROVED lifting identity. For any integers U,V, not both zero, put

    h=min(v_2(U),v_2(V)).

Then

    min(v_2([R1^U R2^V]_theta^2),
        v_2([R1^U R2^V]_theta^3)) = h+2.

Proof: write U=2^h U0,V=2^h V0. The elementary binomial congruence, valid for positive and negative integer exponents, gives

    R1^U R2^V
       = 1+2^(h+2)(U0K1+V0K2) mod 2^(h+3).

For negative exponents invert the corresponding congruence for the positive exponent: the square of 2^(h+2) is divisible by 2^(h+3), so (1+2^(h+2)C)^(-1)=1-2^(h+2)C modulo 2^(h+3). This also explains directly why negative exponents create no extra branch. The indicated drift matrix shows the two normalized marker residues are V0 and U0 modulo2. At least one is odd. This proves the identity.

Both markers can therefore vanish only when U=V=0. It follows that n-mtheta=±1, so (n,m)=(±1,0). From the square cover, Y=1 and X=±1. Together with the i=1 cover this proves the complete auxiliary solution list, and hence the a=1 theorem.

### IV.6. What this answers about the theory

PROVED. A cubic equation on a smooth positive-dimensional local unit germ can become a zero-dimensional local unit problem after a globally necessary cover whose number field is not simply a re-presentation of the original cubic field. Here the cover has a rigorously complete, elementary coverage proof, and the final marker isolation has a rank-two first-order drift certificate at the bad rational prime2.

This should become a separate method card: covariant cover followed by a signature-changing square cover, with finite principalization and full unit coverage. The algebraic form of the cover is reusable for other binary cubics through their Hessian/covariant identity. No claim is made that the resulting quartic forms always have unit rank equal to the number of markers, or that every resulting local residue class is isolatable. Those are separate, explicitly testable conditions.

The statement “every cubic binomial seed fails because the score is presentation-invariant” is not a consequence of presentation invariance. Invariance says changing the cubic presentation cannot create a passing seed when none exists in the original presentation. A finite continued-fraction search, even through denominator 10^220, does not establish that no seed exists. This elementary a=1 proof does not require that universal negative premise.

For the general 165-fibre programme, this proof gives an alternative to improving approximation rates: enumerate the covariant square covers, aim first for quartic orders of signature(2,1), and compile full unit coverage plus a two-marker local atlas. Finite lattice principalization should be treated as part of coverage and certified explicitly, as above, rather than imported as a class-number statement.

### V.1. A cover can change the relevant discrete orbit

is not a rational re-presentation of the same number field. Its complete chain is

Every arrow is justified in Part IV. The first two steps are globally necessary covering conditions. ### V.2. Why quartics with I=0 are promising

For a binary quartic

    Q(X,Y)=aX^4+bX^3Y+cX^2Y^2+dXY^3+eY^4,

define

    I=12ae-3bd+c^2,
    J=72ace+9bcd-27ad^2-27b^2e-2c^3.

Its discriminant is

    disc(Q)=(4I^3-J^2)/27.

These are explicit polynomial identities, checkable by a resultant determinant. For the quartic in Part IV,

    (a,b,c,d,e)=(1,0,-6,-4,-3),
    I=0, J=1296, disc(Q)=-62208.

PROVED structural implication. If Q(T,1) is an irreducible real quartic, I=0 and J!=0, then it has exactly two real roots and one nonreal conjugate pair. Indeed its discriminant is negative, and the sign of the discriminant of a real separable polynomial is (-1)^(number of nonreal pairs). For degree four the only possibility is one such pair.

This signature is compatible with a two-unit, two-marker proof of a binary quartic norm-one equation. It does not by itself prove a unit theorem, produce two units, or make a local drift invertible. The needed replacement for a unit theorem is the concrete normalization test: find two units with independent real logarithmic vectors; round any unit into their compact real parallelogram; prove explicit conjugate and coefficient bounds there; enumerate the remaining norm-one or norm-minus-one elements; verify that they are already generated by the chosen units. Part IV carries out exactly this test.

TARGET: compile covariant square covers and check I=0 for each resulting quartic by its coefficient identity. The familiar j=0 covering interpretation suggests this class, but the proposed compiler should emit the quartic and the identity, rather than invoke that interpretation as a missing proof. Reducible quartics and degenerate conics should be split before unit coverage. Full-rank local isolation and a complete residue atlas are additional checks, not consequences of I=0.

For the Thomas family, the already proved identity

    L^2+27 F_a^2=4d K^3,
    d=a^2+a+7,
    K=x^2+xy+y^2

offers a uniform first stage. For F_a=+/-1, set mu^3=54d^2. Then

    (2dK)^3-54d^2=2d^2 L^2,

so alpha=2dK-mu has norm 2d^2 L^2. This displayed factorization is exact. A practical cover may remove cubes from 54d^2 before choosing its integral lattice; a=1 is a good example where such normalization is essential. Bad-prime and content factors must be recorded, including those above primes dividing 6d. The finite multiplier set, conic coverage and quartic unit boxes remain TARGET for general d. They are not asserted to have bounded size independent of a.

### V.3. A precise certificate theorem for the cover mechanism

PROVED certificate theorem. Let E be an integer equation. Suppose the following finite data have been supplied and verified.

1. Every solution of E lifts to one of finitely many explicitly given equations Norm_(K_j/Q)(z)=h_j, with z constrained to a fixed rational linear subspace V_j of a specified order or fractional lattice. Exceptional denominator and degenerate cases are included in a finite explicit list.
2. Each lifted equation has an exhaustive expression z=s_j eps_(j,1)^n1 ... eps_(j,rj)^nrj, using finitely many seeds s_j. Coverage is proved by explicit factorization/multiplier certificates and a real normalization box; it is not inferred from a list of discovered units.
3. The defining linear conditions for V_j give k_j integral markers after fixed denominators are cleared. A finite congruence atlas covers every integer exponent vector. Each chart either has a congruence contradiction, or explicitly identifies its exponent coset with t in Z^r and its orbit with T^t z for an integral local state z. After a specified integer index shift, z is a known marker zero at t=0. The commuting integral return matrices are T_i=I+p^c K_i, and the k_j by r_j marker drift at z has rank r_j modulo p. Here c>=1 for odd p, and c>=2 for p=2. Alternatively the chart has one of the already proved higher-order primitive-zero certificates with an equally explicit integer zero and chart parametrization. Exact residue tags are retained throughout.
4. For each surviving lifted zero the data give a finite exhaustive list of its integer preimages in E, by inverse formulas with their lattice constraints or by an explicit finite bound and enumeration. Each candidate is checked in E. A chart isolating a nonintegral p-adic index needs a separate certificate excluding all its integer indices; it does not automatically satisfy item 3.

Then E has exactly the finite solution list produced by these pullbacks.

Proof. Take any solution. Item 1 places it in one of the finite lifted equations. Item 2 gives integer exponents in a fully covered orbit. Item 3 places those exponents in a chart. In an excluded chart there is a contradiction. In a first-order chart, write the difference from the known index as p^h times a primitive vector. The binomial return congruence gives a marker vector whose least valuation is c+h, because the drift has full column rank. It cannot vanish unless the index difference is zero. The stated bound on c at p=2 ensures all nonlinear terms have higher valuation; the same argument applies to negative exponents by inversion. A certified higher-order chart has the corresponding conclusion by its primitive-leading-form test. Item 4 leaves precisely the listed integer solutions, and substitution verifies that each is a solution. This proves both exclusion and coverage.

The theorem is deliberately conditional on finite, reviewable input. Its substantial reusable subroutines are the finite lattice principalization, the unit normalization box, and the residue/return compiler. Part IV is an end-to-end instance in which every required input is present.

### V.4. A scalar norm-determinant budget is a useful rejection test

PROVED. Before searching seeds for a scalar construction with coefficients in a totally real field of degree e, compute the budget in Part I:

    principal determinant base = Q/E,
    product of remaining determinant bases = B_*^2.

The nonzero norm forces (Q/E)B_*^2>=1. If the intended degree-d rational approximation theorem requires mu<d and the method's generic norm argument has mu>=2e with d<=2e, this architecture cannot supply the needed strict improvement. Changing a seed, multiplying by a coefficient-field unit, or dividing by certified content leaves the same obstruction for the final integral approximation sequence.

A method can escape by changing a genuine input: additional small errors at other embeddings, special arithmetic information about the unknown cross determinant, a smaller rational approximation lattice, or a globally necessary cover such as Part IV. Merely replacing a radical by an equivalent expression is not such a change.

The coupled construction in Part II avoids this particular real-field budget: its primitive pairs are rational up to a Gaussian unit. Its unresolved cost is instead the growth of the explicitly defined primitive Hankel multipliers. These are different obstacles, and a computation should report them separately.

def moments(count, weights=(4,6,4)):
    out=[Q(0)]*count
    for alpha,c in zip((Q(1,4),Q(1,2),Q(3,4)),weights):
        b=alpha*(1-alpha)/2
        for n in range(count):
            out[n]+=c*b
            b*=Q(n+2-alpha,n+3)
    return out


def trim(a):
    a=list(a)

    return a


def add(a,b):
    out=[Q(0)]*max(len(a),len(b))

    return trim(out)

def solve(A,b):
    a=[list(row)+[v] for row,v in zip(A,b)];n=len(b)

            if i==k:continue

def det(M):
    n = len(M)
    ans = 0
    for p in permutations(range(n)):
        term = (-1) ** sum(p[i] > p[j] for i in range(n) for j in range(i + 1, n))
        for i in range(n):
            term *= M[i][p[i]]
        ans += term
    return ans


class Order:
    def __init__(self, reduction):
        self.red = tuple(reduction)
        self.n = len(self.red)
        self.one = (Q(1),) + (Q(0),) * (self.n - 1)

    def mul(self, a, b):
        c = [Q(0)] * (2 * self.n - 1)
        for i, x in enumerate(a):
            for j, y in enumerate(b):
                c[i + j] += x * y
        for k in range(2 * self.n - 2, self.n - 1, -1):
            for j, r in enumerate(self.red):
                c[k - self.n + j] += c[k] * r
        return tuple(c[:self.n])

    def inv(self, a):
        cols = [self.mul(a, tuple(Q(i == j) for i in range(self.n)))
                for j in range(self.n)]
        M = [list(row) + [Q(i == 0)] for i, row in enumerate(zip(*cols))]
        for i in range(self.n):
            j = next(j for j in range(i, self.n) if M[j][i])
            M[i], M[j] = M[j], M[i]
            v = M[i][i]
            M[i] = [x / v for x in M[i]]
            for j in range(self.n):
                if j != i:
                    v = M[j][i]
                    M[j] = [x - v * y for x, y in zip(M[j], M[i])]
        return tuple(row[-1] for row in M)

    def power(self, a, n):
        if n < 0:
            a, n = self.inv(a), -n
        z = self.one
        while n:
            if n & 1:
                z = self.mul(z, a)
            a = self.mul(a, a)
            n //= 2
        return z

        return det(list(zip(*[self.mul(a, tuple(Q(i == j) for i in range(self.n)))
                              for j in range(self.n)])))

class I:
    def __init__(self, lo, hi=None):
        self.lo, self.hi = Q(lo), Q(lo if hi is None else hi)
        assert self.lo <= self.hi

    @staticmethod
    def coerce(x):
        return x if isinstance(x, I) else I(x)

    def __add__(self, other):
        other = self.coerce(other)
        return I(self.lo + other.lo, self.hi + other.hi)
    __radd__ = __add__

    def __neg__(self):
        return I(-self.hi, -self.lo)

    def __sub__(self, other):
        return self + -self.coerce(other)

    def __rsub__(self, other):
        return self.coerce(other) + -self

    def __mul__(self, other):
        other = self.coerce(other)
        v = [a * b for a in (self.lo, self.hi) for b in (other.lo, other.hi)]
        return I(min(v), max(v))
    __rmul__ = __mul__

    def __truediv__(self, other):
        other = self.coerce(other)
        assert other.lo * other.hi > 0
        return self * I(1 / other.hi, 1 / other.lo)

    def __rtruediv__(self, other):
        return self.coerce(other) / self

    def __pow__(self, n):
        assert n >= 0
        out = I(1)
        for _ in range(n):
            out = out * self
        return out

    def absmax(self):
        return max(abs(self.lo), abs(self.hi))

        den = 10**8
        l = isqrt(self.lo.numerator * den**2 // self.lo.denominator)
        h = isqrt(self.hi.numerator * den**2 // self.hi.denominator) + 1
        return I(Q(l, den), Q(h, den))

"""P08 exact structural identities; standard library only.

This checks the universal binary-quartic discriminant identity symbolically,
the I=0 signature example, and the explicit cyclic-quartic automorphism.
It does not assert a general covariant-cover completeness theorem.
"""
from fractions import Fraction as Q
from itertools import permutations


def add(a, b):
    c = a.copy()
    for mon, value in b.items():
        c[mon] = c.get(mon, 0) + value
        if not c[mon]:
            del c[mon]
    return c


def scale(a, value):
    return {mon: value*x for mon, x in a.items() if value*x}


def mul(a, b):
    c = {}
    for mon, x in a.items():
        for mon2, y in b.items():
            key = tuple(i+j for i, j in zip(mon, mon2))
            c[key] = c.get(key, 0) + x*y
    return {mon: value for mon, value in c.items() if value}


def verify_discriminant():
    variables = [{tuple(int(i == j) for i in range(5)): 1} for j in range(5)]
    a, b, c, d, e = variables
    f = variables
    df = [scale(a, 4), scale(b, 3), scale(c, 2), d]
    rows = []
    for j in range(3):
        rows.append([{}]*j + f + [{}]*(2-j))
    for j in range(4):
        rows.append([{}]*j + df + [{}]*(3-j))
    resultant = {}
    for perm in permutations(range(7)):
        term = {(0, 0, 0, 0, 0): (-1)**sum(perm[i] > perm[j] for i in range(7) for j in range(i+1, 7))}
        for i in range(7):
            term = mul(term, rows[i][perm[i]])
            if not term:
                break
        resultant = add(resultant, term)
    assert all(mon[0] >= 1 for mon in resultant)
    disc = {(mon[0]-1,)+mon[1:]: value for mon, value in resultant.items()}
    inv_i = add(add(scale(mul(a, e), 12), scale(mul(b, d), -3)), mul(c, c))
    inv_j = {}
    for factor, term in (
        (72, mul(mul(a, c), e)),
        (9, mul(mul(b, c), d)),
        (-27, mul(a, mul(d, d))),
        (-27, mul(mul(b, b), e)),
        (-2, mul(mul(c, c), c)),
    ):
        inv_j = add(inv_j, scale(term, factor))
    assert scale(disc, 27) == add(scale(mul(mul(inv_i, inv_i), inv_i), 4), scale(mul(inv_j, inv_j), -1))

    def evaluate(poly, values):
        result = 0
        for mon, coef in poly.items():
            value = coef
            for x, exponent in zip(values, mon):
                value *= x**exponent
            result += value
        return result

    values = (1, 0, -6, -4, -3)
    assert evaluate(inv_i, values) == 0
    assert evaluate(inv_j, values) == 1296
    assert evaluate(disc, values) == -62208
    print('Universal quartic discriminant identity and I=0 example PASS.')


def verify_cyclic_quartic():
    one = (Q(1), Q(0), Q(0), Q(0))
    rho = (Q(0), Q(1), Q(0), Q(0))
    def times(a, b):
        c = [Q(0)]*7
        for i, x in enumerate(a):
            for j, y in enumerate(b):
                c[i+j] += x*y
        for j in range(6, 3, -1):
            c[j-2] += 20*c[j]
            c[j-4] -= 80*c[j]
        return tuple(c[:4])
    def power(a, n):
        v = one
        for _ in range(n):
            v = times(v, a)
        return v
    def lincomb(a, b, r=1, s=1):
        return tuple(r*x+s*y for x, y in zip(a, b))
    sigma_rho = (Q(0), Q(-3), Q(0), Q(1, 4))
    sqrt5 = lincomb(power(rho, 2), one, Q(1, 2), -5)
    assert power(sqrt5, 2) == (5, 0, 0, 0)
    assert power(sigma_rho, 2) == lincomb(one, sqrt5, 10, -2)
    assert times(rho, sigma_rho) == tuple(4*x for x in sqrt5)
    sigma2_rho = lincomb(power(sigma_rho, 3), sigma_rho, Q(1, 4), -3)
    assert sigma2_rho == tuple(-x for x in rho)
    print('Cyclic quartic automorphism rho -> rho^3/4-3rho, square = -rho PASS.')


if __name__ == '__main__':
    verify_discriminant()
    verify_cyclic_quartic()
