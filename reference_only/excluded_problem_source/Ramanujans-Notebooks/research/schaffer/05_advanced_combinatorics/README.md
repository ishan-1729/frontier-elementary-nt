# Schäffer advanced-combinatorics continuation

- `Schaffer_advanced_combinatorics.md`: proofs, hypotheses, and unresolved source obligation.
- `verify_combinatorial_descent.py`: exact verification; requires Python 3.10+ and SymPy.
- `verification_output.txt`: output from the executed checks.

Run:

```sh
python verify_combinatorial_descent.py
```

This is not a proof of the full Schäffer conjecture. The code verifies explicit algebra and combinatorics; it does not construct semistable models or certify a new all-source arithmetic descent.
