1.4 the norm vanishes only at 0
PASS  modulo 2, N(a,b,c) is odd for each of the 7 nonzero residue triples (a,b,c) mod 2 (it is the norm of the field F_2[t]/(t^3 + t + 1) = F_8)
    Descent: if N(a,b,c) = 0 with integers not all 0, divide by gcd(a,b,c); then N is still 0 (N(r u) = r^3 N(u)),
    so N is even and a, b, c are all even, against gcd 1. A rational triple scales to an integer one. So N(u) = 0
    only for u = 0.
